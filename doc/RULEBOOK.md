# Bao Nakakamado ルールブック

**対象：遊べる試作v0.8.0（各人の前列・後列16穴、ハンド22個）**

**更新日：2026年10月2日／文書版：第5版（出典・ライセンス・考案記録を整備。規則はv0.8.0を維持）**

**Bao Nakakamado・NYAKUAの考案者：nkkmd／初公開日：2026年9月30日。** [考案・公開・変更履歴](ORIGIN_AND_HISTORY.md)を参照してください。本書の説明文・図表は[CC BY-SA 4.0](../LICENSE-CC-BY-SA-4.0.txt)です。元資料と変更内容は第10章に記載します。

Bao la Kiswahili の保存済みエンジンを基準とし、NYAKUA（ニャクア、ハンド奪取）を追加した試作です。各人の前列・後列16穴、初期ハンド22個を使います。**NYAKUAで奪った1個は別に確保し、次の自分の手番で通常ハンド2個と一緒に同じ合法な開始穴へ投入します。** 相手の最後の1個と確保分は奪えません。一穴全投入はこの仕様へ置き換えました。

## 1. 勝利条件

次のどちらかを達成すると勝ちです。

- 相手の**前列8穴**をすべて空にする。捕獲の途中でも直ちに終局します。
- 相手の手番に合法手をなくす。

後列にKETEが残っていても、前列が全空なら敗北します。着手処理後に自分の前列が全空になった場合も負けです。KETEの合計数による得点勝負ではありません。ハンドが0になったこと自体は敗北ではありません。

## 2. 盤・用語・初期配置

各人が前列8穴と後列8穴を使い、両者合計**4列32穴**です。穴番号は各人から見て左から1〜8。相手と向き合う側が前列です。

| 用語 | 意味 |
|---|---|
| KETE（ケテ） | 石・種。両者合計64個 |
| 通常ハンド | 初期22個からまだ盤へ投入していない手元のKETE。相手のNYAKUAで減ることがある |
| 確保分 | NYAKUAで得た1個。通常ハンドと分け、次の自分の手番で必ず使う |
| NAMUA（ナムア） | ハンドを使う段階 |
| MTAJI（ムタジ） | 両者の通常ハンドと確保分がすべて空になり、盤上だけで指す段階 |
| takata（タカタ） | 一着手を通じて捕獲しない手 |
| 連続種まき | 終点のKETEを持ち上げ、同じ着手を続けること |
| NYUMBA（ニュンバ） | 自分の前列5番にある特別な穴 |
| kichwa（キチュワ） | 前列の両端1番・8番。捕獲したKETEの入口 |
| kimbi（キンビ） | 前列2番・7番。捕獲時の入口に制約がある穴 |
| NYAKUA（ニャクア） | NAMUAの連続捕獲後に相手のハンドから1個奪う動作 |
| 次手3個投入 | 通常ハンド2個と確保分1個を次の自分の手番で同じ合法穴へ投入する動作 |

各人の初期配置は次のとおりです。

| 自分から見た穴番号 | 1 | 2 | 3 | 4 | 5：NYUMBA | 6 | 7 | 8 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 前列 | 0 | 0 | 0 | 0 | 6 | 2 | 2 | 0 |
| 後列 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

各人の盤上10個、ハンド**22個**、計32個です。両者ともNYUMBAを所有した状態で、SOUTHが先手、NORTHが後手。NAMUAから交互に指します。

画面ではSOUTHの前列をSF1〜SF8、後列をSB1〜SB8、NORTHをNF/NBで表示します。NORTHの番号は画面では反転します。真向かいの前列穴は番号の合計が9です。SF5の真向かいはNF4で、両者のNYUMBAは真正面ではありません。

## 3. 前列・後列を循環する種まき

種まきは**自分の前列と後列の16穴だけ**を使います。相手の穴へ蒔きません。前列の端の次は、後列の同じ側の端へ進みます。

| 方向 | 経路の例 |
|---|---|
| 前列を右へ | …F6 → F7 → F8 → B8 → B7 → … → B1 → F1 → F2… |
| 前列を左へ | …F3 → F2 → F1 → B1 → B2 → … → B8 → F8 → F7… |

穴から持ち上げたKETEは開始穴の**次の穴**から1個ずつ蒔きます。捕獲したKETEは指定された前列入口の**穴そのもの**へ最初の1個を置き、その後は内側へ進みます。

ひとまとまりの種まきが終わるたび、最後の1個を置いた穴で判定します。

1. 最後の1個を置く直前に空だった穴なら、1個を残して着手終了。
2. 空ではなかった穴なら、捕獲手ではまず捕獲できるかを確認。
3. 捕獲しない場合、NAMUAのNYUMBA停止規則を確認。
4. 止まらなければ終点のKETEを持ち上げ、同じ方向へ連続種まき。

途中で通過した穴では判定しません。一着手中に何回続いても、途中で相手の手番にはなりません。takataで始めた手は、その着手全体を通じて捕獲しません。

## 4. NAMUA：ハンドを使う段階

### 捕獲手

自分の前列で、KETEがあり、真向かいの相手前列にもKETEがある穴を探します。1つでもあれば、必ずそのいずれかで捕獲します。

1. 合法な自分の前列穴へ通常ハンドから1個を投入。確保分があれば第6章の合計3・2・1個を投入。
2. 真向かいの相手前列穴のKETEを**すべて**取る。
3. 捕獲したKETEを指定された自分の前列入口から蒔く。
4. 終点に応じて、さらに捕獲・連続種まきを続ける。

開始穴に元からあったKETEと投入分はその穴に残し、捕獲したKETEとは一緒に持ち上げません。NYUMBAも、条件を満たせば捕獲の開始穴にできます。

### 捕獲手がなければtakata

合法な**前列**の開始穴へ通常1個、確保分があれば第6章の合計3・2・1個を投入し、投入後の中身を持ち上げ、左右いずれかへ蒔きます。後列からは開始しません。NYUMBAの2個蒔きは例外です。

- 空穴からは開始できません。通常は2個以上ある前列穴を使います。
- NYUMBAを所有していれば1個の穴も選べます。所有していなくても、通常の開始候補に2個以上の穴がなければ1個の穴を選べます。
- 所有中で6個以上のNYUMBAは通常のtakata開始穴にできません。前列で所有中NYUMBAだけにKETEがある場合は、第7章の2個蒔きです。
- 自分の前列を空にする禁止手は選べません。合法な候補は画面で光ります。

## 5. 捕獲の入口と連続捕獲

捕獲するのは相手の**前列**です。後列やハンドを通常の盤上捕獲で取りません。NYAKUAによるハンド奪取は第6章の別処理です。

| 自分の捕獲穴 | NAMUAの最初の捕獲 | 同じ着手の後続捕獲・MTAJI |
|---|---|---|
| 前列1・2番 | 左入口（前列1番） | 左入口 |
| 前列3〜6番 | 左か右を選ぶ | 前列を右へ進む方向なら左入口、左へ進む方向なら右入口 |
| 前列7・8番 | 右入口（前列8番） | 右入口 |

種まきの終点が自分の前列で、最後の1個を置く直前に空ではなく、真向かいの相手前列にKETEがあれば、捕獲手ではさらに全捕獲します。後列を終点とする場合は捕獲せず、通常の連続種まき判定をします。

相手前列が全空になった時点で終局し、最後に取ったKETEを蒔き直しません。棋譜内部ではその分を保留数として記録し、総数を保存します。

## 6. NYAKUAと次の自分の手番での3個投入

### NYAKUAの発動と別確保

NAMUAで始めた一着手で、次の条件を満たすと相手の**通常ハンドから1個だけ**奪い、自分の確保分へ移します。

- 同じ着手で捕獲が**2回以上**。
- 相手の通常ハンドに**2個以上**残っている。

数えるのは捕獲した穴の回数です。3回以上続いても奪うのは1個。相手の通常ハンドが0〜1個、捕獲1回以下、MTAJIでは発動しません。**相手の最後の1個と、相手がすでに確保した分は奪えません。** 奪取分は通常ハンドへ混ぜず、画面に「確保」として別表示します。

例：自分の通常ハンド6個・相手2個で、通常1個を投入して2回捕獲すると、自分は通常ハンド5個・確保分1個、相手は通常ハンド1個になります。

NYAKUAは追加手番を与えません。相手の手番を挟み、次の自分の手番で確保分を必ず使います。終局した着手にも条件を満たす奪取を記録しますが、勝敗を変えたり対局を再開したりしません。

### 確保分がある手での投入

| 手番開始時の通常ハンド | 確保分 | 通常ハンドから使う数 | 一穴への合計投入数 |
|---|---:|---:|---:|
| 2個以上 | 1個 | 2個 | **3個** |
| 1個 | 1個 | 1個 | **2個** |
| 0個 | 1個 | 0個 | **1個** |
| 1個以上 | 0個 | 1個 | **1個** |

1. 通常のNAMUAの合法手から開始穴と方向・入口を選ぶ。捕獲義務も維持。
2. 通常の1個投入を、上表の合計数を同じ穴へ一度に置く処理に置き換える。
3. その後の捕獲・takata・連続種まき・NYUMBA判定を通常どおり行う。

空穴へ自由に置いたり、複数の穴へ分けたり、別々の着手として繰り返したりしません。捕獲手では投入分を開始穴に残し、捕獲分だけを入口から蒔きます。NYUMBAの2個蒔きが適用される手は、3個投入後も2個だけを蒔きます。

**この3個投入の手でもNYAKUAが発動します。** 古い確保分を投入してから、新たな1個を次の自分の手番用に確保します。確保分を温存する選択はありません。相手のハンドが0でも残り全部の一括投入は行いません。

### 共通MTAJIへ移行・パス

両者の**通常ハンドと確保分がすべて0**になったら、現在の着手をNAMUAの規則で最後まで処理し、終局しなければMTAJIへ移ります。通常ハンド0でも確保分が1個あれば、その1個を投入するNAMUAの手です。片側だけ先にMTAJIへ入ることはありません。

通常の初期局面ではハンド枯渇によるパスは生じません。残数だけを扱う全170状態・323遷移で確認しました。人工局面で手番側の通常ハンド・確保分が両方0、相手に残数がある場合を扱う互換用パス処理は残します。

NYAKUAは総KETEを増やさず、各NAMUA着手で合計1個以上を盤へ投入します。着手が正常に完了する限り44手以内にNAMUAを終えます。一着手内やMTAJI全局面の停止証明とは別です。

## 7. NYUMBA

自分の前列5番はNYUMBAです。穴の位置と所有状態を区別します。

NAMUAの種まきが、所有中で6個以上あるNYUMBAを終点とした場合：

| 状況 | 処理 |
|---|---|
| takata | 停止 |
| 捕獲手で真向かいから捕獲できる | 捕獲を優先し、停止不可 |
| 捕獲手で真向かいが空 | 「止める」か「使う」を選択 |

「止める」は所有を保って着手終了。「使う」は中身を持ち上げ、同じ方向へ蒔き、所有を失います。所有中でも6個未満なら上記の停止機能は働きません。相手にNYUMBAの全KETEを取られた場合や、穴を空にする処理でも所有を失います。一度失った所有は、KETEが増えても戻りません。

NAMUAで捕獲手がなく、前列で所有中NYUMBAだけにKETEがある場合、ハンドを投入後に**2個だけ**持ち上げて左右へ蒔きます。3個投入でも2個蒔きは同じです。例えばNYUMBA6個・通常ハンド2個以上・確保分1個なら、3個投入して9個から2個を蒔き、7個残します。

MTAJIではNYUMBAを通常の穴として扱い、特別な停止・2個蒔きは使いません。

## 8. MTAJI：前列・後列の盤上で指す

ハンドからは投入せず、NYAKUAもハンド・確保分の投入もありません。

**捕獲手**は、前列または後列の2〜15個の穴から全数を蒔き、終点が自分の前列で既にKETEがあり、真向かいの相手前列にもKETEがある手です。捕獲手があれば必ず選びます。最初の種まき後に全捕獲し、連続処理を続けます。

捕獲手がなければ**takata**です。前列に2個以上の開始候補があれば前列から、なければ後列の2個以上の穴から始めます。開始穴の全数を左右へ蒔き、その着手では捕獲しません。自分の前列を空にする禁止手は選べません。

16個以上の穴は捕獲手の開始には使えませんが、takataには使えます。0〜1個の穴からはMTAJIの着手を開始できません。後列に動かせる穴があっても、前列全空による敗北が優先されます。

## 9. 画面・棋譜・実装範囲

「対局設定」で2人対戦か簡易コンピューター対戦を選び、開始します。光る穴を選び、方向・入口・NYUMBAの選択肢を選んでください。上からNORTH後列、NORTH前列、SOUTH前列、SOUTH後列の順に32穴を表示します。高速再生、サウンド、棋譜JSON保存に対応します。

棋譜はversion 7、`rulesVersion: "0.8.0"`、`boardRowsPerPlayer: 2`、`sowingPath: "ring"`、`initialHand: 22`、`totalKete: 64`、`nyakuaProtectLast: true`、`nyakuaFixedPitBulk: false`、`nyakuaNextTurnThree: true`、`nyakuaReservedProtected: true`です。盤の `reserve` は通常ハンド、`nyakuaReserve` は確保分、`pending` は終局時の盤上捕獲保留分です。各着手の `placed`（合計）・`ordinaryPlaced`・`reservedPlaced`・`captures`・`stolen` を保存します。画面での棋譜読み込みは未実装です。

実行エンジンは `next-turn-engine.js`、奪取層は `steal.js` です。元ゲームの[採用ルール基準](https://github.com/nkkmd/bao-la-kiswahili-game/blob/main/doc/RULES_BASELINE.md)を出発点にします。takasia未実装、連続種まき512回の安全上限など、保存済みエンジンの実装範囲を引き継ぎます。すべての大会・地域の規則への完全な準拠を主張しません。

**MTAJIの一部局面で一着手内の種まき循環が発生する既知の制約があります。** この実装でも連続種まき512回の安全上限で対局を停止します。画面では通常の勝敗と区別し、棋譜の `adjudication: "safety-stop"` を正規終局とは扱いません。元エンジンとの再現用に内部の `winner`・`reason: "relay-limit"` は保持します。循環時の正式な停止規定は別途検討が必要です。

先後均衡は未確認です。旧1列盤の勝率・必勝証明はこの条件へ適用しません。NYUMBA残数による部分捕獲上限は採用せず、毎回全捕獲を維持します。[3個投入の比較調査](NYAKUA_THREE_STUDY_20261002.md)と[実装・検証記録](NYAKUA_THREE_ADOPTION_20261002.md)を参照してください。
