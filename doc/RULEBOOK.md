## 1. 勝利条件

2人で対戦し、次のどちらかを達成すると勝ちです。

- **相手の前列8穴をすべて空にする。** 着手の途中でも、捕獲によって相手の前列が空になれば直ちに勝ちます。
- **相手の手番に合法手をなくす。** 捕獲手がなくても、非捕獲手があれば対局は続きます。

着手の処理後に、自分の前列がすべて空なら負けになります。そのため、前列に唯一残った端の穴を、後列へ向かって空にする非捕獲手は選べません。

盤上やハンドのKETEの多さだけで勝敗を決めることはありません。捕獲したKETEも、通常は自分の盤上へ戻して対局を続けます。

**ハンドが0になったこと自体は敗北ではありません。** NAMUA中のパスについては第8章を参照してください。

## 2. 盤と用語

盤は **4列×8穴、合計32穴** です。各プレイヤーは、自分に近い2列、合計16穴を使います。

| 用語 | 意味 |
| --- | --- |
| KETE（ケテ） | 対局に使う石・種。合計64個。色や種類による区別はありません |
| 前列 | 盤の中央で相手の前列と向き合う、自分側の8穴 |
| 後列 | 自分の手前にある8穴 |
| ハンド | まだ盤上へ投入していない、手元のKETE |
| NAMUA（ナムア） | ハンドのKETEを使って着手する段階 |
| MTAJI（ムタジ） | 両者のハンドが空になり、盤上のKETEだけで着手する段階 |
| takata（タカタ） | 一着手を通じて捕獲しない、非捕獲手 |
| 連続種まき | 種まきの終点にあるKETEを持ち上げ、同じ着手を続けること |
| NYUMBA（ニュンバ） | 自分から見て、前列の左から5番目にある特別な穴 |
| kichwa（キチュワ） | 前列の両端、1番と8番。捕獲したKETEの入口になる穴 |
| kimbi（キンビ） | 前列の2番と7番。捕獲時の入口に制約がある穴 |
| NYAKUA（ニャクア） | 条件を満たした着手の後に、相手のハンドからKETEを1個奪う動作 |
| 一穴全投入 | 相手のハンドが0のとき、自分の残りのハンドを選んだ一穴へ一度に置く動作 |

### 穴番号と向き

穴番号は、**各プレイヤー本人から見て左から1〜8** です。左右の方向も、そのプレイヤーの視点で考えます。

試作画面では、SOUTHの前列を `SF1〜SF8`、後列を `SB1〜SB8`、NORTHの前列を `NF1〜NF8`、後列を `NB1〜NB8` と表示します。画面の上側にいるNORTHは、画面上で番号の並びが反転します。

| SOUTHの前列 | 真向かいのNORTHの前列 |
| --- | --- |
| SF1 | NF8 |
| SF2 | NF7 |
| SF3 | NF6 |
| SF4 | NF5 |
| SF5 | NF4 |
| SF6 | NF3 |
| SF7 | NF2 |
| SF8 | NF1 |

例えば、SF5の真向かいはNF4です。両者のNYUMBAは、互いに真正面ではありません。

## 3. 初期配置

各プレイヤーは32個ずつのKETEを持ち、次のように配置します。

| 自分から見た穴番号 | 1 | 2 | 3 | 4 | 5：NYUMBA | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 前列 | 0 | 0 | 0 | 0 | 6 | 2 | 2 | 0 |
| 後列 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

盤上は10個、ハンドは22個です。両者とも、自分のNYUMBAを所有した状態で始めます。

**SOUTHが先手、NORTHが後手** です。NAMUAから開始し、原則として交互に着手します。パスも一手番として扱い、相手へ手番を渡します。

## 4. 種まきと一着手の流れ

### 4.1 種まきの経路

種まきでは、持ち上げたKETEを **1穴に1個ずつ** 順に置きます。自分の前列と後列の16穴を一周する経路を使い、相手の穴には蒔きません。

| 選んだ方向 | 前列での進み方 | 後列での進み方 |
| --- | --- | --- |
| 右回り | 1番から8番へ | 8番から1番へ |
| 左回り | 8番から1番へ | 1番から8番へ |

右回りでは、前列8番の次は後列8番、後列1番の次は前列1番です。左回りはその逆です。

通常、穴から持ち上げたKETEの最初の1個は、**開始穴の次の穴** に置きます。捕獲したKETEを入口から蒔く場合は例外で、**入口の穴そのもの** に最初の1個を置きます。

### 4.2 最後の1個を置いた穴で判定する

種まきのひとまとまりが終わるたびに、最後の1個が入った穴を確認します。

1. **最後の1個が入る直前に空だった穴** なら、そこに1個を残して着手を終えます。
2. 空ではなかった穴なら、捕獲手ではまず捕獲できるかを確認します。捕獲できれば第6章の処理を続けます。
3. 捕獲を行わない場合は、NYUMBAの停止規則を確認します。
4. 停止規則に当てはまらなければ、その穴のKETEをすべて持ち上げ、同じ方向へ蒔き続けます。これが連続種まきです。

途中で通過した穴の中身は持ち上げません。判定するのは、**最後の1個を置いた穴** です。

一着手に何度種まきや捕獲が続いても、その途中で相手の手番にはなりません。方向は通常そのままですが、捕獲時に入口が指定されると変わる場合があります。

### 4.3 捕獲手とtakataを区別する

捕獲できる合法手がある場合は、必ず捕獲手を選びます。複数あるときは、その中から選べます。

takataとして始めた手は、**その着手全体を通じて捕獲しません。** 途中で相手のKETEと向き合う形になっても、捕獲手へ切り替えることはありません。

## 5. NAMUA：ハンドを使う段階

### 5.1 まず捕獲できる穴を探す

自分の前列で、次の両方を満たす穴を探します。

- 自分の穴にKETEが1個以上ある。
- 真向かいの相手の前列穴にもKETEが1個以上ある。

1つでも見つかれば、必ずそのいずれかで捕獲します。

1. 自分のハンドから、選んだ自分の穴へKETEを投入します。通常は1個、一穴全投入の条件下では残り全部です。
2. 真向かいの相手穴のKETEをすべて取ります。
3. 捕獲したKETEを、自分の前列の入口から蒔きます。
4. 終点に応じて、捕獲または連続種まきを続けます。

**自分の捕獲穴に元からあるKETEと、投入したKETEは、その穴に残します。** 捕獲したKETEと一緒には持ち上げません。

所有中のNYUMBAに6個以上あっても、捕獲の開始穴として使える条件を満たせば、そこから捕獲できます。

### 5.2 捕獲手がなければtakata

合法な開始穴へハンドからKETEを投入し、その穴のKETEを持ち上げ、左回りか右回りへ蒔きます。NYUMBAの2個蒔きを除き、投入後の中身をすべて持ち上げます。

開始穴には次の制約があります。個数は **投入前** の数で判定します。

- 前列の、KETEが入っている穴から始めます。空穴や後列は選べません。
- 通常は2個以上ある穴を選びます。
- ただし、自分のNYUMBAをまだ所有している場合は、1個の穴も選べます。所有していない場合でも、選べる前列の開始穴に2個以上の穴がなければ、1個の穴を選べます。
- 6個以上ある所有中のNYUMBAは、通常のtakataの開始穴には選べません。前列で所有中のNYUMBAだけにKETEがある場合は、第9章の2個蒔きを使います。
- 前列で唯一KETEがある穴が1番または8番なら、そこを空にして後列へ進む方向は選べません。

### 5.3 最初の一手の例

初期配置では捕獲手がありません。SOUTHがSF7から左回りを選ぶ例です。

1. ハンドから1個をSF7へ入れ、SF7を2個から3個にします。
2. SF7の3個を持ち上げます。
3. SF6、SF5、SF4へ1個ずつ置きます。
4. 最後のSF4は投入直前に空だったので、そこで終わります。

SOUTHの前列は1番から順に **0・0・0・1・7・3・0・0**、ハンドは21個になります。途中で通過したSF5のNYUMBAでは止まりません。この手はtakataなので、捕獲もNYAKUAも起こりません。

## 6. 捕獲と入口の選択

### 6.1 捕獲するのは相手の前列

捕獲では、真向かいの相手の前列穴から **全KETE** を取ります。後列やハンドのKETEは、通常の捕獲では取りません。

捕獲したKETEは自分のkichwaから内側へ蒔きます。

- **左入口**：自分の前列1番へ最初の1個を置き、2番、3番の方向へ進みます。
- **右入口**：自分の前列8番へ最初の1個を置き、7番、6番の方向へ進みます。

### 6.2 入口の決まり

捕獲穴とは、相手からKETEを取る際に使う **自分側の前列穴** を指します。

| 自分の捕獲穴 | NAMUAの最初の捕獲 | 同じ着手内の後続捕獲・MTAJIの捕獲 |
| --- | --- | --- |
| 1番・2番 | 左入口 | 左入口 |
| 3番〜6番 | 左入口か右入口を選ぶ | 直前の種まきの方向を維持する入口 |
| 7番・8番 | 右入口 | 右入口 |

中央の3〜6番で方向を維持するときは、右回りなら左入口、左回りなら右入口です。端の1・2番、7・8番では入口の指定が優先され、種まきの方向が変わることがあります。

### 6.3 一着手の中で捕獲を続ける条件

捕獲手の種まきが終わったとき、次の条件をすべて満たせば、さらに捕獲します。

- 最後の1個が自分の前列へ入った。
- その穴は最後の1個が入る直前に空ではなかった。
- 真向かいの相手の前列穴にKETEがある。

捕獲を済ませてから、そのKETEを指定された入口へ戻して蒔きます。最後の1個が空だった穴へ入った場合は、相手の穴にKETEがあっても着手を終えます。

**捕獲によって相手の前列がすべて空になった場合は即座に終局** し、最後に捕獲したKETEを蒔き直す処理は行いません。

## 7. NYAKUA：ハンドからKETEを奪う

### 7.1 発動条件

次の条件をすべて満たす着手の後に、NYAKUAが発動します。

- NAMUAで始めた着手である。
- **同じ一着手の中で、捕獲が2回以上** 起きた。
- 相手のハンドにKETEが1個以上残っている。

相手のハンドからKETEを **1個だけ** 取り、自分のハンドへ移します。盤上へは置きません。

捕獲回数には、NAMUAの最初の捕獲と、その後の種まき中に起きた捕獲を含めます。数えるのは捕獲した **穴の回数** であり、捕獲したKETEの個数ではありません。

| 一着手の結果 | NYAKUA |
| --- | --- |
| 1つの穴からKETEを10個捕獲 | 発動しない：捕獲は1回 |
| 2回捕獲し、相手のハンドが残っている | 1個奪う |
| 3回以上捕獲し、相手のハンドが残っている | 1個奪う：奪取数は増えない |
| 2回以上捕獲したが、相手のハンドが0 | 発動しない |
| MTAJIで2回以上捕獲 | 発動しない |

NYAKUAは追加手番を与える仕組みではありません。処理後は、通常どおり相手の手番になります。

### 7.2 ハンドの数え方

自分のハンドが6個、相手が1個で、自分の通常のNAMUA着手でNYAKUAが発動したとします。

| 処理 | 自分のハンド | 相手のハンド |
| --- | --- | --- |
| 着手前 | 6 | 1 |
| 通常の1個投入後 | 5 | 1 |
| NYAKUA後 | 6 | 0 |

通常の投入で1個減り、NYAKUAで1個戻るため、自分のハンドは着手前と同じ6個になります。相手は0個です。この後は、第8章のパスと一穴全投入へ進みます。

現行試作では、終局した着手でも条件を満たせばNYAKUAを結果に記録します。勝敗は変わらず、対局を再開することもありません。

## 8. ハンドの枯渇・パス・一穴全投入

### 8.1 片側だけハンドが0ならNAMUAを続ける

両者のハンドが空になるまでは、対局全体の段階はNAMUAです。**ハンドが空になった側だけ先にMTAJIへ入ることはありません。**

| 自分の手番開始時のハンド | 相手のハンド | その手番の処理 |
| --- | --- | --- |
| 1個以上 | 1個以上 | 通常のNAMUA：1個投入 |
| 0個 | 1個以上 | パスして相手へ手番を渡す |
| 2個以上 | 0個 | 一穴全投入 |
| 1個 | 0個 | 通常と同じ1個投入 |
| 0個 | 0個 | 前の着手が終わって対局が続くなら、MTAJIへ移行済み |

ハンドが0の側に与えられるパスは、NAMUAの特別な処理です。盤上に動かせそうなKETEがあっても、MTAJIの着手を行うことはできません。

### 8.2 一穴全投入の手順

自分の手番の開始時に、相手のハンドが0、自分のハンドが2個以上なら、次のように着手します。

1. **従来のNAMUAの合法手から、開始穴と方向・入口を一度選びます。** 捕獲できるなら捕獲義務があります。空穴や後列へ自由に投入することはできません。
2. 自分のハンドの全KETEを、選んだ **一穴へ一度に** 置きます。
3. その後は、通常のNAMUAと同じ捕獲またはtakata、連続種まき、NYUMBA、終局判定を行います。

変更されるのは、最初の投入が「1個」から「ハンドの残り全部」になる点だけです。

捕獲手なら、投入した全KETEは自分の捕獲穴に残り、相手から捕獲したKETEを入口へ蒔きます。通常のtakataなら、開始穴に元からあったKETEと投入した全KETEをまとめて持ち上げ、次の穴から蒔きます。NYUMBAの2個蒔きが適用される手は、第9章どおり2個だけを蒔きます。

ハンドを複数の穴へ配ったり、残数分の通常着手を繰り返したり、途中で新しい開始穴を選んだりはしません。

### 8.3 相手の最後の1個を奪った場合の例

第7章の例の続きです。

1. 自分の着手でNYAKUAが発動し、自分のハンドが6個、相手が0個になります。
2. **次の相手の手番はパス** です。
3. 次の自分の手番で合法手を選び、ハンドの6個を一穴へ一度に置きます。
4. 捕獲や種まきを通常どおり処理します。
5. 途中で終局しなければ、着手終了時に両者のハンドが0なのでMTAJIへ移り、相手がMTAJIの手を指します。相手に合法手がなければ、その時点で終局します。

相手のハンドを0にした直後の同じ着手の途中で、追加の全投入を行うわけではありません。

### 8.4 段階移行の時期

ハンドが両方0になっても、現在処理中の着手はNAMUAのルールで最後まで進めます。途中でMTAJIのルールへ切り替えません。終局しなければ着手終了時にMTAJIへ移行します。

NYAKUAと一穴全投入があるため、NAMUAが終了するまでの手番数は、元の初期配置の「合計44手番」に固定されません。

## 9. NYUMBA：特別な穴

NYUMBAは、SF5とNF5です。初期配置では6個入り、それぞれのプレイヤーが所有しています。**穴の位置** と **特別な機能を使える所有状態** を区別します。

### 9.1 NAMUAの種まきがNYUMBAで終わった場合

最後の1個を置いた後、自分のNYUMBAが **所有中で6個以上** なら、次の規則を使います。

| 着手の種類・状況 | 処理 |
| --- | --- |
| takata | NYUMBAで止まる。中身を持ち上げて続けない |
| 捕獲手で、真向かいの相手穴から捕獲できる | 捕獲を優先する。停止は選べない |
| 捕獲手で、真向かいの相手穴が空 | 止まるか、NYUMBAの中身を使って続けるかを選ぶ |

「nyumbaを止める」は、その着手を終えて所有状態を保つ選択です。「nyumbaを使う」は、中身をすべて持ち上げ、現在の方向へ種まきを続ける選択で、所有状態を失います。

試作画面では、この選択によって結果が変わる手について、着手候補に「nyumbaを止める」「nyumbaを使う」を表示します。種まきの途中で改めて選び直すのではなく、着手時に選びます。

所有中でも6個未満なら、6個以上を条件とする停止規則は働きません。所有状態が残り、NAMUA中に再び6個以上になれば、その停止規則を使えます。

### 9.2 前列でNYUMBAだけにKETEがある場合

NAMUAで捕獲手がなく、前列で **所有中のNYUMBAだけ** にKETEがある場合は、特別な開始方法を使います。

1. ハンドからNYUMBAへ投入します。通常は1個、一穴全投入ならハンドの残り全部です。
2. 投入後のNYUMBAから **2個だけ** 持ち上げます。
3. 左回りか右回りへ、次の穴から蒔きます。
4. その後は通常のtakataとして連続種まき・停止を判定します。

例えば、NYUMBAに6個、ハンドから通常の1個を投入する場合、7個から2個を蒔き、NYUMBAには5個残ります。

一穴全投入でも、この2個蒔きの例外は変わりません。例えばNYUMBAに6個、ハンドに6個なら、全投入後は12個になり、そのうち2個を蒔いて10個残します。

### 9.3 所有状態とMTAJI

相手にNYUMBAの全KETEを捕獲された場合や、捕獲手で「nyumbaを使う」を選んだ場合などに、所有状態を失います。所有状態を失った後は、KETEが再び6個以上になっても特別な機能は戻りません。

MTAJIでは、NAMUAの2個蒔きやNYUMBAでの特別な停止を使いません。通常の穴として、MTAJIの開始条件と捕獲・連続種まきの規則で扱います。所有状態の実装上の細則は、第13章に記載します。

## 10. MTAJI：盤上だけで指す段階

両者のハンドが0になるとMTAJIです。ハンドからKETEを追加せず、盤上の穴から始めます。NYAKUAと一穴全投入は発動しません。

### 10.1 捕獲手を先に探す

次の条件をすべて満たす開始穴と方向を探します。

- 自分の前列または後列にある穴である。
- 開始穴に **2個以上15個以下** のKETEがある。
- 開始穴の全KETEを次の穴から蒔くと、最後の1個が、自分の **すでにKETEがある前列穴** へ入る。
- その真向かいの相手の前列穴にもKETEがある。

捕獲手があれば、必ずその中から選びます。最初の種まきの後に捕獲し、入口から蒔き直します。入口は第6章の後続捕獲と同じ規則で決まります。

捕獲手は後列からも始められます。前列に捕獲できない穴があるという理由で、捕獲義務を避けることはできません。

### 10.2 捕獲手がなければtakata

- 2個以上ある穴の全KETEを持ち上げ、左回りか右回りへ蒔きます。
- 前列に2個以上の開始穴があれば、前列から始めます。後列を選べるのは、前列に2個以上の開始穴がないときです。
- その着手の途中では捕獲せず、同じ方向で連続種まきを行います。
- 前列で唯一KETEがある穴が端の穴なら、そこを空にして後列へ進む方向は選べません。

**16個以上の穴は捕獲手の開始穴には使えませんが、他の条件を満たすtakataの開始穴には使えます。** 空穴と1個だけの穴は、MTAJIの開始穴に使えません。

自分の16穴すべてが0個または1個になれば、合法手がなく敗北します。

## 11. 試作画面での操作

1. 「対局設定」で2人対戦か簡易コンピューター対戦を選びます。コンピューター対戦では、自分がSOUTHかNORTHかも選びます。
2. 「対局開始」を押します。
3. 手番のプレイヤーが、光っている穴を選びます。
4. 表示された方向・入口・NYUMBAの選択肢から、着手を選びます。
5. 画面が投入・捕獲・種まき・NYAKUAを順に再生します。再生中は次の着手を選べません。

一穴全投入の手番では投入数を表示します。NYAKUAが起こる着手候補には、その旨を表示します。合法手と各処理は画面が判定します。

上部の「高速」で再生を速められます。「サウンド」で効果音を切り替えます。どちらも初期状態はOFFです。「新しい対局」で再生を中断し、対局設定へ戻ります。

盤面下の「棋譜の保存」を開き、「棋譜を保存」で対局のJSONを保存できます。現行画面から保存済み棋譜を読み込む機能はありません。対戦相手のコンピューターは試作用の簡易相手であり、元ゲームのAI-GEN4ではありません。

## 12. よくある疑問

### 2個以上のKETEを捕獲すればNYAKUAですか？

いいえ。必要なのは、一着手の中で **捕獲が2回以上** 起きることです。1回の捕獲で何個取っても、NYAKUAは発動しません。

### 奪ったKETEはどこへ置きますか？

自分のハンドへ加えます。捕獲した盤上のKETEを蒔く処理とは別です。

### 相手のハンドを0にしたら、相手は次にMTAJIを指しますか？

いいえ。自分のハンドが残っていれば、相手の次の手番はNAMUAのパスです。その後、自分が一穴全投入を行い、終局せず両者のハンドが0になればMTAJIへ移ります。

### 一穴全投入なら、どの穴にも置けますか？

いいえ。通常のNAMUAの合法な開始穴を選びます。捕獲義務やNYUMBAの制約も続けて適用します。

### ハンドが6個なら、6回に分けて着手しますか？

いいえ。最初に選んだ一穴へ **6個を一度に** 置き、その一着手を処理します。

### takataの途中で捕獲できる形になったら捕獲しますか？

いいえ。takataはその着手全体で非捕獲です。

### NYAKUAや一穴全投入を避けるため、任意にパスできますか？

できません。NAMUAでハンドが0の側に与えられるパス以外は、合法手があれば着手します。

### ハンドが空でも、盤上のKETEが多ければ勝ちですか？

個数だけでは勝敗を決めません。第1章の前列全空または合法手なしで決まります。

### 13.2 実装上の細則

**連続種まきの安全上限**：ブラウザーの処理を保護するため、継続処理を512回に制限しています。上限に達してなお継続中なら、現行試作では着手側の敗北（`relay-limit`）として終局します。人間対局のための一般的なルールとして追加された規則ではありません。

**NYUMBAの所有状態**：現行コードは、相手の捕獲で空になったとき、捕獲手でNYUMBAを使ったとき、連続種まきでNYUMBAの全内容を持ち上げたとき、MTAJIの開始でNYUMBAを空にしたとき、MTAJIで自分が捕獲したときに、自分または該当する側の所有状態を解除します。NAMUAの通常takataの開始で、6個未満の所有中NYUMBAから全内容を持ち上げる処理では、所有状態の解除を行っていません。基準資料の「空になれば所有状態を失う」という説明と差があるため、本書では現行のコード上の扱いとして記録します。この細則を新しい確定ルールとして採用したという意味ではありません。

**終局時のKETE**：相手の前列を空にした最後の捕獲では、捕獲したKETEを蒔き直す前に終局します。棋譜内部ではそのKETEを終局保留分として管理するため、終局画面の盤上とハンドの合計だけでは64個にならない場合があります。
