## 結論と範囲

ニャクアの奪取・別確保・次手での投入まで含む盤面専用の軽量遷移を整備し、128局に沿った6,776局面・24,887候補遷移が通常処理と一致した。既存の調査用の独立した会計照合とも一致し、全128局の棋譜再構築と24,887件の南北交換を確認した。不一致0件、専用7件を含む既存回帰44件が通過した。

判定は **対象局面での遷移整合確認済み**。探索アルゴリズム・学習・新AIの画面組込み・棋力比較は未実施。通常の公開ルール、棋譜version 7、簡易コンピューターを維持する。性能改善、先後均衡、全局面の停止、AI-GEN4相当の棋力を確認した結果ではない。

## 実装

- `steal.js`：通常処理と探索で使うニャクアの会計を共通化。盤面だけを受け取る `applyMoveForSearch` と `moveVariantsForSearch` を追加した。
- `search-transition.js`：v0.8.0用の探索アダプターを追加。合法variantの展開と軽量遷移の両方にニャクアを含める。
- 局面識別：盤面、通常ハンド、確保分、NYUMBA権利、手番、段階、勝者、終了理由、捕獲保留、手数、規則ID・版を含める。
- 安全停止：`outcome` で `relay-limit` を通常終局と区別する。探索時の評価方法は後続工程で設計する。

生の `BaoEngine.applyMoveForSearch` はニャクアの会計を含まないため、将来のAIの接続先として直接使わない。新しいアダプターの探索遷移は表示用スナップショットと累積棋譜を生成しないが、盤面のJSONコピーと軽量イベントは残す。

## 到達局面の照合

`seedAt(500000+i)`、i＝0〜31を、random・noisy・greedy・replyの各方針で使用した。方針間でseedを共有する128局であり、128独立標本による統計検定ではない。既存調査ツールが生成した軌跡の各局面から全候補を比較した。

| 項目 | 件数 |
|---|---:|
| 軌跡 | 128局 |
| 軌跡上の局面 | 6,776 |
| 照合した全候補遷移 | 24,887 |
| 南北交換した候補遷移 | 24,887 |
| 全棋譜の再構築 | 128局 |
| NAMUA候補 | 15,808 |
| MTAJI候補 | 9,079 |
| NYAKUA発動 | 2,384 |
| 3個投入 | 2,711 |
| 2個投入 | 204 |
| 確保分だけの1個投入 | 25 |
| 捕獲2回以上でも相手の最後の1個を保護 | 147 |
| 相手の確保分が存在する候補 | 2,658 |
| NYUMBAのstop / use | 各269 |
| 通常終局に至る候補 | 287 |
| 段階が移行する候補 | 437 |

候補数は局面間の重複を含む。通常処理は `applyWithEvents`、調査用の会計照合は `T.advance(state, move, true)` を使用し、最終盤面と手の集計を比較した。通常・探索は共通の会計処理を使うため、その比較だけでは共通の誤りを検出できない。調査用照合は歴史エンジンへ合算ハンドと投入数を渡して分離し直す別経路であるが、歴史エンジン自体は共有する。これはルール全体の独立実装による数学的証明ではない。

入力盤面と手を凍結し、非変更を検査した。演出用イベントから局面スナップショットとsteal演出を除いたメタデータが探索のeventsと一致し、探索結果に累積棋譜とイベント局面コピーがないことを確認した。到達局面では総KETE64個と非負整数を検査した。

軌跡と候補結果のSHA-256：`7fc8c90978be16b090b62438420880029a6266bde4d3dc31b84b8f44b4c3d6de`。ソースハッシュとseed一覧は結果JSONを参照。

## 境界条件と検証器の確認

専用テストで、奪取→相手の手番→3個投入→再奪取、人工ハンド0/1/2/5、相手の通常ハンドと確保分の保護、共通MTAJIの延期と移行、人工局面のパス、NYUMBAの2個蒔き、終局時の捕獲保留、終局後の合法手なしを確認した。人工局面は境界条件用であり、標準初期局面からの到達を主張しない。

保存済みの `self-random-three-3435580265-game.json` の最後の手で、通常・探索とも同じ `relay-limit` 局面となり、アダプターは `safety-stop` を返した。局面識別について、確保分を含む全盤面フィールドと規則IDが異なる場合にキーが変わることを確認した。ブラウザー形式のスクリプト読み込みはVMで確認した。

奪取省略、確保分消失、捕獲数の誤り、表示用局面コピーの混入、累積棋譜の混入という5種の故意の誤りを、照合がすべて検出した。

## 実行とCI
