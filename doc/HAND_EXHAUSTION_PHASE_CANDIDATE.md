# ハンド枯渇時の段階移行 — 次の検討項目

Status: 検討候補・未採用  
記録日: 2026-09-29  
対象: Bao Nakakamado 遊べる試作 v0.4、`main` コミット `70f8235949ec69f694a864e78cb6c2ca2cda5d22`

## 問いと現行動作

NAMUA中の連続捕獲で相手のハンドからKETEを奪えるため、両者のハンドが異なる速さで減る。片方のハンドが先に空になった場合、どのように次の着手を与えると、選択の余地とゲームバランスを保てるかを検討する。

現行の [`prototype/engine.js`](../prototype/engine.js) は、NAMUA中に自分のハンドが空になるとパスを合法手とする。両者のハンドが空になるまでは全体の段階がNAMUAのままなので、相手だけが実質的に続けて着手する。両者のハンドが空になった後、MTAJIへ移る。試作 v0.4 はこの方式で動いている。

## 次に比較する案

ハンドが空になった側だけ、その次の手番からMTAJIの合法手で指す。相手は自分のハンドが残る間NAMUAで指し、相手のハンドも空になれば両者がMTAJIとなる。したがって対局中に両者の段階が異なる局面を認める案である。KETE奪取はNAMUAで着手した側にのみ適用し、着手の途中で段階を切り替えない。

ゲームバランスの観点から先行MTAJIを次の試作・検証の優先候補とする。ただし、まだルールにも製品コードにも採用していない。実装前に、次の境界を明文化する必要がある。

1. ハンドから最後のKETEを使った場合と、相手に最後の1個を奪われた場合の、次の手番の段階。
2. 片側だけMTAJIのときの捕獲義務、nyumba、合法手、終局判定。MTAJIの合法手がない場合は通常の `no-move` 敗北とするか。
3. 両者の段階を局面・棋譜・画面でどう表し、既存の一つの `phase` 値を使う処理をどう更新するか。
4. KETE総数の保存、ハンド間移動、段階移行と棋譜再現の整合。

## 探索的な比較

2026-09-29に、現行ルールと先行MTAJI案をそれぞれ1,000局ずつ、二通りの同条件の手選びで比較した。先行MTAJI案は元のエンジンをメモリ上で一時的に変え、次のプレイヤーのハンド残数からその手番の段階を選んだ。KETE奪取後も次のプレイヤーの段階を照合し、MTAJIの合法手がなければ `no-move` 敗北とした。製品コードは変更していない。

| 手選び | 方式 | 先にハンドが空になった側の勝ち | SOUTH勝利 | `no-move` 終局 | 平均手数 |
| --- | --- | ---: | ---: | ---: | ---: |
| 合法手からランダムに選択 | 現行パス | 75 / 765（9.8%） | 522 / 1,000（52.2%） | 42 / 1,000（4.2%） | 43.1 |
| 同上 | 先行MTAJI | 232 / 765（30.3%） | 559 / 1,000（55.9%） | 146 / 1,000（14.6%） | 51.7 |
| 簡易的な一手評価、18%はランダム | 現行パス | 32 / 541（5.9%） | 487 / 1,000（48.7%） | 28 / 1,000（2.8%） | 35.6 |
| 同上 | 先行MTAJI | 97 / 541（17.9%） | 494 / 1,000（49.4%） | 183 / 1,000（18.3%） | 38.4 |

一手評価は終局を優先し、前列のKETE差を3倍、盤上とハンドの保有KETE差を1.5倍、ハンド差を0.3倍として評価した。各方式で両者に同じ手選びを適用した。ランダム手選びは初期seed `(i + 1) × 1973`、一手評価は `(i + 1001) × 1373`（`i = 0..999`）から、同じ線形合同法で選択を進めた。1局240手を上限とし、いずれもその前に終局した。

先行MTAJIでは、先にハンドが空になった側の勝率が上がった。一方、`no-move` による終局も大きく増えた。SOUTHの勝率は手選びによって方向が変わり、この試験だけでは先後差について優劣を決められない。単純な手選びと仮の段階切替による探索であり、強いAIや人間同士の対局での均衡を示すものではない。試験コードも正式な検証手順として固定していない。

## 次の判断手順

1. 上記の混合段階と `no-move` の扱いを仕様として固定し、元の合法手・捕獲・段階移行との整合をテストする。
2. 同じ開局局面を先後入れ替えで比較し、先後勝率、先にハンドが空になった側の勝率、`no-move` の頻度、対局手数、KETE奪取回数を測る。手選び方針とseedを固定し、再実行できる試験として残す。
3. 人間同士の対局で、パスの連続と先行MTAJIの両方について、理解しやすさと逆転可能性を確認する。
4. この結果を踏まえて採用・修正・不採用を決める。それまでは現行パス方式を維持する。
