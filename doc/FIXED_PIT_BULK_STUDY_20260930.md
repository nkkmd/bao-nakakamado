# NAMUAの一穴全投入案 — 局面と先後差の探索的調査

Status: 調査記録・**未採用**  
調査日: 2026-09-30（日本時間）  
基準: `main` `3578637cf4ba912fcc088518b1e7eef6954b23e5`、試作 v0.4

追記: この調査後、一穴全投入を[試作 v0.5](FIXED_PIT_BULK_TRIAL_20260930.md)に試用実装した。以下の「画面未実装」「v0.4」は**調査時点**の記述であり、試用と正式採用は異なる。

## 検討するルール

NAMUAで相手のハンドが0、自分のハンドが2個以上ある場合、次の自分の手番で合法な穴・方向を一度だけ選ぶ。自分のハンドの全KETEを**選んだ一穴へ置いてから**、その着手の捕獲またはtakata、連続種まき、nyumba、終局を通常のエンジンどおり処理する。捕獲の途中でハンドのKETEを分配しない。残りが1個なら通常のNAMUA着手、両者が0になれば通常どおりMTAJIへ移行する。相手が0になった直後の相手の手番には現行どおりパスが入る。終局すれば途中で手番を打ち切る。

選んだ穴から各穴へ1個ずつ置く案、通常の投入を同じ手番で繰り返す案、片側だけ先にMTAJIへ入る案とは異なる。KETE奪取は現行試作どおり「NAMUAの一着手に2回以上の捕獲、相手ハンドが残る場合は1個」。相手ハンドが0の全投入では奪取は起こらない。

調査用の[`tools/fixed-pit-bulk-study.cjs`](../tools/fixed-pit-bulk-study.cjs)は元のエンジンのNAMUA投入部分だけをメモリ上で置き換える。調査時点の製品の[`prototype/engine.js`](../prototype/engine.js)と[`prototype/steal.js`](../prototype/steal.js)、画面は変更しなかった。元の合法手、捕獲・連続種まき、houseChoice、勝敗・段階移行を共用する。

## 同条件の対局比較

先攻をSOUTHとする1,000局ずつ、同じseedで現行パス方式と一穴全投入案を比較した。両側へ同じ手選び方針を適用。開始側をNORTHへ反転した試験では勝敗と終局理由が完全に反転・対応した。下表の先攻勝率はSOUTH先攻の1,000局のみであり、反転局は独立試行として加算しない。

| 手選び | 方式 | 先攻勝ち | 先にハンドが空になった側の勝ち | `no-move` 終局 | うち全投入直後 | 平均手数 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 無作為 | 現行パス | 468/1,000（46.8%） | 72/763（9.4%） | 36 | 0 | 43.3 |
| 同上 | 一穴全投入 | 507/1,000（50.7%） | 229/763（30.0%） | 147 | 8 | 49.4 |
| 簡易評価＋揺らぎ | 現行パス | 506/1,000（50.6%） | 24/535（4.5%） | 13 | 0 | 35.4 |
| 同上 | 一穴全投入 | 510/1,000（51.0%） | 108/535（20.2%） | 71 | 7 | 37.0 |
| 一手評価 | 現行パス | 458/1,000（45.8%） | 21/555（3.8%） | 24 | 0 | 35.5 |
| 同上 | 一穴全投入 | 470/1,000（47.0%） | 99/555（17.8%） | 169 | 19 | 37.5 |

勝者が変わった局は無作為177局（先攻勝ちへ108、後攻勝ちへ69）、揺らぎ86局（45、41）、一手評価84局（48、36）。一穴全投入が発生した局は順に656、444、468局。相手が0でない局は元ルールと同じで、奪取を無効にした対照試験では各方針1,000局ずつ、両方式の最終局面・勝敗が完全に一致した。各条件に未終局はなく、400手上限へ達した対局はなかった。

応手を一手だけ読む簡易方針でも300局を比較した。両方式とも先攻186勝、全投入は0件、勝者の変化0件だった。この方針の対局では奪取が起きず、**全投入ルールを評価できていない**。強いプレイヤーでの均衡を示す結果には使わない。

手選びは[先攻・後攻差の前回調査](FIRST_PLAYER_BALANCE_20260929.md)と同じ評価式で、終局優先、`2 × 前列差 +（盤上とハンドの全KETE差）`、捕獲手+2点。無作為は一様、揺らぎは最高値から7点以内を一様、一手評価は最高値から一様に選ぶ。応手評価は各候補の相手応手後の最悪値で選ぶ。xorshift32、初期seedは `0x924f3aa1 + i × 0x9e3779b1` の32ビット値（`i = 0..N-1`）。ただし本試験は候補が一手しかない場合に乱数を消費しないため、前回の試験とは軌跡と数値を直接合算しない。

## 追加試験：発動局面からの応手評価

応手評価を初期局面から使うと全投入が発動しないため、現行エンジンで実際に到達した「片方のハンドだけ0、相手のハンドが2個以上、NAMUA、未終局」の**最初の局面**を採取し、そこから現行パス方式と一穴全投入方式を同じ手選びで再開した。局面を作る手選びは無作為、簡易評価＋揺らぎ、一手評価の3通り。seed index `0..1999` と `2000..3999` の二群から、各手選び・各群・先に空になった側ごとに200局面を採取した。計2,400標本（局面としては2,398種類、重複2件）、残ったハンドは2～18個である。

再開後の手選びは「応手評価」（全候補について相手の次の全合法応手の最悪値で選択）と「一手評価」の2通り。両者に同じ方針を使い、各局面を南北反転して再実行した。2,400局面すべてで全投入が実際に起こり、反転後の勝敗・理由・手数は全て対応した。下表の手数は採取局面**以降**の残り手数であり、初手からの対局手数ではない。

| 再開後の手選び | 局面数 | 先に空の側の勝ち：現行 → 全投入 | `no-move`：現行 → 全投入 | うち全投入直後 | 平均残り手数：現行 → 全投入 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 応手評価 | 2,400 | 29 → 346 | 47 → 582 | 75 | 5.0 → 13.4 |
| 一手評価 | 2,400 | 53 → 476 | 53 → 714 | 75 | 4.5 → 8.7 |

先に空になったのがSOUTHかNORTHかを各1,200局面にそろえると、応手評価での全投入案のその側の勝ちは176対170、一手評価では227対249だった。これはハンド枯渇後の条件付き比較であり、ゲーム全体の先攻勝率ではない。先に空になった側の勝つ余地が増えた一方、全投入後にMTAJIで進む時間と `no-move` が大幅に増える傾向を、より先を読む手選びでも確認した。`no-move` の多くは全投入直後ではない。

## 追加試験：初期局面からの探索入り応手評価

全投入が発動するゲーム全体でも先後差を見るため、次の二方針を両者に同条件で適用し、各1,000局をseed index `0..499` と `500..999` の二群に分けて比較した。「応手評価＋揺らぎ」は応手後の最悪値が最高値から7点以内の手を一様選択。「応手評価＋10%探索」は着手候補が複数あるとき10%の確率で一様選択し、残りは応手評価の最高値から選ぶ。いずれも固定seedの試作用方針であり、人間の棋力や強いAIを表さない。

| 手選び | 先攻勝ち：現行 → 全投入 | 全投入した対局 | 先に空の側の勝ち：現行 → 全投入 | `no-move`：現行 → 全投入 | 全投入直後 | 平均手数：現行 → 全投入 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 応手評価＋揺らぎ | 485 → 522 | 729 | 152/961 → 332/961 | 109 → 252 | 22 | 51.6 → 59.0 |
| 応手評価＋10%探索 | 514 → 526 | 689 | 137/926 → 282/926 | 93 → 194 | 13 | 50.7 → 57.5 |

両方針・両seed群で南北を反転した結果は全件対応し、未終局はない。奪取を無効にした各条件の対照でも、両方式の最終局面・勝敗は一致した。先攻勝率は全投入案で52.2%と52.6%だったが、現行との差は方針・seed群によって変わり、**明確な先攻有利がないと証明したわけではない**。二方針とも手数と `no-move` は増える。最初から応手評価のみを使った300局で発動が0だったことも併せ、方針への依存は大きい。

## `no-move` の局面確認

無作為方針の最初の3,475局から、**全投入直後**に `no-move` となる30例を抽出し、全投入前後の盤面とMTAJI合法手を調べた。30例とも両ハンドが0になり、次の側には実際にMTAJI合法手がなく、元エンジンの `no-move` 判定と一致した。KETEの負数や総数の不一致はない。

- 30例中24例では、全投入の直前ならハンドが空の側にMTAJI合法手が1手以上あった。全投入中の捕獲などで着手可能な配置が失われた。
- 6例では直前からMTAJI合法手がなかった。別の切り口で、全投入側のどの合法な選択でも直後の `no-move` となる例が6例あった。両方に当てはまるのは5例であり、同じ集合ではない。
- 24例には、全投入側が別の合法手を選べば**直後の** `no-move` を避ける選択があった。ただし別の敗北理由で終わる選択も含む。これは空ハンド側がその時点で応手できるという意味ではない。

具体例として、`case 23 random` は39手目、SOUTHのハンド6個・NORTHのハンド0。NORTHの前列には9個の穴を含めMTAJI候補が2手あるが、SOUTHの全投入捕獲後は前列が `[0,1,0,1,0,0,0,0]`、後列が全て0となり、NORTHのMTAJI合法手は0。SOUTHには全投入前に4つの着手候補があり、うち2つがこの即時終局を生む。`case 875 random` は全投入前から空ハンド側のMTAJI合法手が0で、全投入側の4候補すべてで即時 `no-move` となる。

空ハンド側が**最後にパス以外の手を指した時点**へ戻り、別の合法手を選んだ場合を限定的に調べた。その後の相手の全合法応手と、ハンドが空ならパス後の全投入を列挙し、直後の敗北を全応手で避けられる選択を数えた。30例中22例に少なくとも1つあり、8例にはなかった。これは最大2回の相手着手までの局所的な検査であり、「8例は必敗」も「22例は最終的に勝てる」も意味しない。全投入直後には空ハンド側の応手はないため、直前の選択や盤面表示から危険を読み取れるか、人間の対局で確認する必要がある。

増えた `no-move` の**大半は全投入の直後ではない**。上表の全投入直後は8/147、7/71、19/169件。両者がMTAJIへ移った後、さらに着手を進めた時点の終局が大半を占める。合法手なしの増加を一律に「全投入の即死」と表現しない。

## 整合確認・限界と判断

到達可能な局面のテストで、捕獲手とtakataの両方、一穴へ全KETEが置かれた時点の状態、残り1個では通常着手となること、15個の全投入、nyumbaの停止・継続の区別、直接の `no-move` 判定、奪取なしの対照一致を確認した。シミュレーションの全着手で、盤上・両ハンド・終局保留分のKETE総数64、ハンド非負、`no-move` 時の合法手0を検査する。

初期配置を先後反転してもこの試験では席の固有差はなく、複数の手選びでは新たな大きい先攻偏りは現れなかった。ただし簡易方針は最善手を表さず、強めの方針では発動頻度も変わる。**先攻後攻の均衡は未確認**である。さらに、全投入でパスは減ったが平均手数はむしろ延び、早い決着も確認できなかった。これはMTAJIに進む対局が増えた影響と考えられるが、手選び依存の観察である。

一穴全投入案は技術的な明白な破綻が見つからず、検討候補として維持する。採用前に、実際の画面で全投入量・捕獲・段階移行・敗北理由を追えるようにしたうえで人間同士の対局を確認する。さらに公開AI相当の強さや異なる開局条件でも、全投入の発動、先後差、終局の質を再評価する。調査時点の試作 v0.4 は現行パス方式のままだった。[3案の暫定比較](HAND_EXHAUSTION_OPTIONS_REVIEW_20260930.md)では、個別MTAJI案との違いと人間対局での確認項目を整理した。

## 再現

リポジトリのルートから Node.js v24 で実行する。試験コードの `summary` はJSON行で比較条件を表示する。`cases` は直接の `no-move` 例、`avoid` は上記の限定的な直前選択の検査、`case` は指定seedの全投入前後の盤面を表示する。

```sh
node --test tools/fixed-pit-bulk-study.test.cjs
node tools/fixed-pit-bulk-study.cjs summary 1000 random,noisy,greedy
node tools/fixed-pit-bulk-study.cjs summary 300 reply
node tools/fixed-pit-bulk-study.cjs summary 500 reply-noisy,reply-eps10 0
node tools/fixed-pit-bulk-study.cjs summary 500 reply-noisy,reply-eps10 500
node tools/fixed-pit-triggered-study.cjs 2000 200 0 reply
node tools/fixed-pit-triggered-study.cjs 2000 200 2000 reply
node tools/fixed-pit-triggered-study.cjs 2000 200 0 greedy
node tools/fixed-pit-triggered-study.cjs 2000 200 2000 greedy
node --test tools/fixed-pit-triggered-study.test.cjs
node tools/fixed-pit-bulk-study.cjs cases 5000 random 30
node tools/fixed-pit-bulk-study.cjs avoid 5000 random 30
node tools/fixed-pit-bulk-study.cjs case 23 random
```

結果は簡易方針と固定seedによる探索的証拠であり、人間の実力差、プレイヤーの学習、最適な指し方を評価していない。調査時点で画面は未実装だった。v0.5で遷移表示を追加したが、視認性・納得感の人間による確認は残る。
