# v0.10.0 調査019：早期の別合法手と全応手の探索計画

計画日：2026年10月19日（Asia/Tokyo）。基準main `251e93c353da856f451a89ae60c29aec3b34ac0f`、[018結果PR #59](https://github.com/nkkmd/bao-nakakamado/pull/59)統合。 [018結果](V010_BALANCE018_RESULTS_20261019.md)／[018計画](V010_BALANCE018_PLAN_20261018.md)。

## 目的と問い

実戦上の破綻を判断するため、018で後攻baseに負け続けた「7左→5左」の先攻に、AIが選ばなかった早い抵抗手があるかを調べる。018の勝率を精密化する同経路の大量反復を優先しない。公開ルール・初期配置・公開AIは変更しない。初期理論値UNKNOWN、既存52着手／43着手の局所証明を保持し、新しい必勝証明は対象外。

018は全3,072局が通常終局だったが、同じ先攻方針で全12条件に耐える候補はなかった。一方、5左後に合法な6右は017・018の該当条件では未観測だった。選択されなかったことは敗北や無効の証明ではない。

## 既存記録の再利用と被覆

通常エンジンで3手目全2候補と直後の後攻全合法応手を列挙した。6左後は5応手、6右後は6応手、合計11経路。[入力一覧](v010-balance019/input-inventory.json)は経路と完全状態キーを保持する。[生成器](../tools/v010-balance019/inventory.cjs)は合法列挙のみでAIを呼ばない。

[読取り専用の索引照合](v010-balance019/prior-index.json)で旧001〜003の原ZIP内の全games.turns.beforeを、017 registryのopening-2-1の完全状態キーに一致照合した。同一向きの状態で001は14着手すべて6左、002・003は一致0だった。これは原棋譜の索引照合であり、全棋譜の新たな独立監査や全履歴の網羅確認ではない。反転座席・状態の同型性・001〜016の証明義務の照合は未完。6右が過去の全研究で未調査だとは断定しない。

実装前に、旧10,240局・001〜016・017・018を正規化した同一状態／経路で照合し、既存の対局・局所証明・有限手数反証を分けたcoverage receiptを保存する。SHA・固定manifest・原数値は保持し、既存成果を新規標本に数えない。同じsource・seed・経路・方針・予算の完成jobを再実行しない。既存証明があれば通常独立検証器による原記録再監査を優先するが、新規証明探索へ自動移行しない。

## 固定候補設計

| 項目 | 設計値 |
|---|---|
| 対象 | 7左→5左を共通prefixとし、3手目6左・6右の両方を強制 |
| 自然応手比較 | 3手目まで強制した2根。4手目以降はAIが選ぶ |
| 全応手比較 | 4手目まで強制した11根。5手目以降はAIが選ぶ |
| 継続方針 | 先攻base／mobility × 後攻base／mobilityの全4組合せ |
| 訪問数上限 | 双方同じ2,048／8,192／32,768。全root全幅窓・厳密同評価選択・静止探索1・最大深度32 |
| セル・件数 | (2+11)根 × 4方針組 × 3予算 =156セル。各4交換組、624組・1,248局 |
| seed | 新domain `BALANCE019-EARLY-BRANCH-SCREEN-20261019-v1`。同じpair indexを根・方針・予算間で対応。固有seedは4個で条件間は対応データ。全seed・衝突検査を封印 |
| 座席交換 | 方針を先後役割に固定して物理座席だけを交換。交換2局を独立2標本にしない |
| 保存 | forced prefix、全状態、合法手、chosen move、seed、両方針、要求／実測ノード、深度、時間、停止理由、source/run/manifest |

6左を対照として残し、後攻の応手は全数を含める。018の敗局で観測した後攻応手だけを選ばない。forcedの4手目を探索量や自然な手選択の成功として数えない。3手目まで強制の結果と4手目まで強制の結果を合算しない。同方針比較を条件付き先後差、異方針比較を相手変更診断として分ける。

4交換組では同時区間が広く、対抗策の成立・不存在を統計確認できない。各セルの通常勝敗と未終局、交換一致、棋譜／prefix数を記述し、必要なら156セル同時95%Hoeffding区間と未終局最悪割当の両端を表示する。探索的な4組全勝を018の64組全勝と同じ証拠の強さで扱わない。勝率を全条件でプールしない。

## 選定・停止・成功条件

研究完了条件は、全設計セルの保存・全件性・通常エンジン再生・SHAとsource/run/manifestの一致・独立集計の一致である。勝つ候補がなくても019は完了し得る。

候補選定では、各3手目・先攻方針を固定した単位で、全後攻応手・両後攻方針・全予算の結果を表にする。まず通常終局の先攻最低成績、次に交換組の勝敗反転数、prefix多様性を併記し、候補を都合のよいセルごとに取り替えない。全条件で通常先攻勝利が1組以上観測された固定候補を後続確認の優先候補とするが、有効性の確認成功とは呼ばない。この条件を満たさない候補にも全表を残し、0勝を必敗・対抗策不存在にしない。

一部の候補が負けた場合、5手目以降の別合法手が残る。最初の敗局seedにおける最初の先攻自由選択局面を、全合法手数・既選択手とともに読取り専用で記録する。019の結果を見て対象を増殖させず、追加の継続試験は別計画にする。全4初手・14応手の旧被覆表も保持する。019だけでゲーム全体の破綻・公平を決めない。

循環・安全停止・400手上限・中断・通常終局は別分類。未終局は引き分けや0.5点へ変えない。欠測・不完全組・不正棋譜はHOLD。深度0・非通常終局は件数を全て記録し、該当セルの候補選定をHOLDとする。勝敗による早期停止・不利セル除外・追加標本は禁止する。

## 運用予算と実装前の関門

1. 既存記録とのcoverage receipt、全13根・156セル・全seed一覧、通常エンジン合法性を固定する。現行sourceをコピーして新研究ディレクトリで実装し、017・018固定sourceは編集しない。
2. 交換対称性、強制手の計数、異方針役割、予算上限、改ざん拒否、未完組HOLD、通常終局再生を小規模検証する。
3. 正式と別domainの運用試走を全156セル各1交換組、312局まで、合計runner12時間以内で行う。これは探索標本へも確認標本へも合算しない。勝敗によって正式条件を削らず、時間・メモリ・保存量を測る。12時間以内の試走完了見込みが事前に立たなければ起動せず分割・予算を改訂する。
4. 正式は暫定52分割×12交換組、同時4、各job120分、合計runner96時間上限。実測に基づく各job予測が84分以下、全体予測が67.2時間以下でなければ封印・起動しない。予測wall timeは現時点未確定。タイムアウトは計算上の引き分けではない。
5. source・入力・workflow・seed・分割・計画・試走receipt・予算をmanifestへ封印する。独立監査・隔離PRのチェック後、起動記録を残してActionsで1回だけ正式起動する。今回の計画作成では実装・試走・正式起動を行わない。
6. run_attempt>1を自動起動しない。中断時は完成原bytesを監査・再利用し、started markerを消さず、未完jobを自動再探索しない。保存障害は完成artifact回収で扱う。

## 後続の確認試験への接続
