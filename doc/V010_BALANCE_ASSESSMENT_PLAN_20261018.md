## 研究目的と対象

主目的は、**先攻・後攻の有利差の不均衡により、対等な相手との対戦で一方が一方的に勝ちやすく、十分な対抗策が失われるようなゲームバランスの破綻がないかを確認すること**である。途中局面の必勝証明を増やすこと自体を最終目標にしない。

対象は現行ルールv0.10.0・標準初期配置である。初期配置からの最善プレイ時の理論値と、指定したAI・計算量での実戦上の先後差を分けて調べる。標準初期配置での結果を、全合法配置・全技能水準・すべてのルール派生の公平性へ一般化しない。ルール・初期配置・公開AIを、この研究のために変更しない。

「初期配置でどちらかが必勝」であることだけで実戦上の破綻とは判定しない。勝ち方の難しさ、対抗策の豊富さ、条件を変えても偏りが残るかを別に確認する。逆に、理論値が未確定でも、広い検証条件で同じ側に容易な勝ち筋があり、抵抗手段が乏しければ、実戦上の問題として報告する。

## 残り工程

| 工程 | 作業 | 成果物と次へ進む条件 |
|---|---|---|
| 1. 評価基準を固定 | 問題とする先後差の幅、対抗策、勝ち方の難しさ、循環・非終局を定義する | 判定指標・許容幅・不確実性・必要標本数・停止条件を、新規確認試験の前に固定 |
| 2. 同条件の交換対局 | 同じAI実装・同じ予算で先後を交換し、評価方針・探索量・乱数条件を変えて偏りの頑健性を確認 | 条件別の勝敗・未決着・先後差と不確実性。条件を混ぜた単一勝率で結論を出さない |
| 3. 初期開幕の対抗策 | 初期4合法初手・14応手を全列挙し、不利側が別の合法手で抵抗できるか検証 | 全開幕の被覆表、既知証明・実戦結果・未解決の区別。単一AIの選ぶ開幕だけに依存しない |
| 4. 偏りの原因追跡 | 同じ側が容易に再現できる勝ち筋、敗着への厳しさ、抵抗側の選択肢を調べる | 全合法候補の評価範囲と、計算量・方針を変えた対抗検証。AIの癖とルール由来の問題を区別 |
| 5. 初期配置の理論解析 | 証明が判定に寄与する分岐へ探索を集中し、必要な存在／全称条件を初期配置まで接続 | 通常エンジンによる独立証明検証、被覆表、未解決義務。循環・非終局を通常勝利にしない |
| 6. 総合判定 | 実戦評価と理論解析を適用範囲付きで併記する | 「破綻を確認」「調べた範囲では確認されず」「判断保留」と、初期理論値の証明済み／未確定を別々に報告 |

工程2〜4と5は並行可能とし、実戦上の評価を完全な理論解析の完了まで保留しない。ただし実戦的な「確認されず」は数学的な破綻不在の証明ではない。

## 実戦評価の設計条件

- AI実装・評価方針・手番・探索予算・乱数seed・開幕を識別し、先後交換した組を対応づける。異なるAI同士の比較では棋力差と手番差を分離する。同一決定的条件の反復を独立標本として数えない。
- 訪問数予算を揃えた比較と、実時間予算を揃えた比較を分ける。実行環境・停止理由・実測使用量を残し、要求上限と実際の使用量を混同しない。探索量を増やしたときに偏りが維持・反転・縮小するかを見る。
- 勝ち・負け・規則上の引き分け・循環検出・安全停止・手数上限・中断を区別する。未終局を自動的に引き分けや0.5点へ割り当てない。採点を使う場合は定義と別扱いの集計を事前に固定する。
- 勝率だけでなく、先後差の区間推定、開幕間の偏り、対抗策の有無、勝ち方の再現性を報告する。seed・開幕・対局組の依存を考慮した集計単位を明示する。AIによる「有望手」は数学的な有効対抗策の証明とは区別する。
- 「差が有意でない」を「公平」としない。許容幅に収まることを評価する設計と、深刻な偏りを検出する設計を分け、必要な精度・標本数・予算停止時の判断保留条件を事前に固定する。現段階で数値閾値・必要局数は未決定である。
- AI条件内の頑健性を、人間の技能水準全般へ一般化しない。人間での遊びやすさや対抗策の発見難度を結論に含める場合は、別途その評価方法を定める。

## 理論解析の証明条件

初期先攻勝ちは、4初手のうち勝つ初手1つについて全後攻応手を覆う必要がある。初期後攻勝ちは、全4初手それぞれに勝つ応手が必要。その先も勝者の手番では少なくとも1手、相手の手番では全合法応答を覆い、通常勝利末端へ至る証明を通常エンジンの独立検証器で確認する。

局所証明や一本道の到達例は、初期配置からの強制到達の証明ではない。循環・安全停止を勝利にしない。有限手数の反証・未証明・資源停止から、無期限の勝利・引き分け・公平・必勝不在を導かない。非終局の理論値を扱うときは、現行ルールの終局定義と必要な循環解析の条件を別途固定する。
