# NYAKUA：蒔き終わりの穴へ2個追加する2案

記録日：2026年10月6日（Asia/Tokyo）。状態：**未採用・未実装・未試験の検討案**。現行規則はv0.8.0です。

## 提案の経緯と記録範囲

nkkmd（管理者）から、現行の「連続捕獲後に奪取分を別確保し、次の自分の手番で3個投入する」規則に代えて、「蒔き終わりの穴に相手と自分のハンドのKETEを追加で2つ入れる」案が提示されました。AI支援による検討で、追加後に終了する案と、追加後も処理を続ける案を整理し、管理者から両案をリポジトリに記録する指示を受けました。

新案の提案者はnkkmd、2通りの処理の整理・比較はAI支援によるものです。記録の承認を規則の採用承認として扱いません。正式な新ルール版、実装日、配信日、性能評価結果はありません。

## 現行規則と共通の検討前提

[現行ルールブック](RULEBOOK.md)のv0.8.0では、NAMUAで始めた一着手の捕獲が2回以上、相手の通常ハンドが2個以上なら、着手後に相手から1個だけ奪います。奪取分を別確保し、次の自分の手番で通常ハンド2個と同じ合法な開始穴へ投入します。通常ハンドが1個なら計2個、0個なら確保分1個です。

新案は、次の前提で比較対象として記録します。細則は試験設計前に確定する必要があります。

- 「追加で2個」は、自分の通常ハンド1個と相手の通常ハンド1個、計2個と解釈する。これは今回の議論での解釈であり、細則の確定ではない。
- 通常のNAMUA開始時の1個投入は維持し、追加分は同じ着手中に自分の蒔き終わりの穴へ置く。
- NAMUA・一着手の捕獲2回以上という発動条件と、相手の最後の1個保護を維持する前提で比較する。
- 発動は一着手に1回とする案を推奨する。3回目以降の捕獲ごとに2個ずつ追加する案とは区別する。
- 自分に追加用の1個、相手に2個以上が残る場合にだけ、両者から1個ずつ同時に使う案を推奨する。自分の残数不足時の片側だけの投入は未確定。
- 現行の別確保・次手3個投入を置き換える案であり、両方を併用して二重に投入する案ではない。追加手番も与えない。

総KETEを増やす案ではなく、両者のハンドから盤へ移す案です。新案には次手用の奪取分を保持する必要がなくなる見込みですが、実装・棋譜形式は未設計です。

## 案A：着手終了後に追加し、手番を終える

通常の捕獲・連続種まき・NYUMBAの選択を最後まで処理し、着手が終了した終点へ計2個を追加します。追加による捕獲・連続種まき・NYUMBA停止判定のやり直しは行わず、相手の手番へ渡します。

例えば、空穴への最後の1個で通常の着手が終わり、NYAKUA条件を満たしていれば、その穴は追加後に3個になります。この追加を理由に中身を持ち上げて蒔き直すことはありません。

期待する効果は、連続捕獲の成果がその手の終点の補強として見え、終点を選ぶ戦略が生まれることです。厚くした穴を相手に全捕獲される可能性もあり、常に利益となるとは限りません。管理と説明が簡単になる可能性から、まず比較試験する案として推奨します。これらは未検証の見通しです。

後列終点、NYUMBAでの停止、捕獲による即時終局などの扱いは、下記の未確定事項に従って試験前に明文化します。

## 案B：種まきの終点に追加し、処理を続ける

一着手中の種まきの区切りで、NYAKUAの発動条件を満たした終点に計2個を追加し、その穴について捕獲・連続種まき・NYUMBAの判定を行って処理を続ける案です。追加で再び捕獲が起きても、一着手1回という検討前提では追加投入を繰り返しません。

本来は空穴への最後の1個で止まる場面も、追加後は3個になるため、続行する規定を設ければ着手が続く可能性があります。ただし、現行は「最後の1個を置く直前に空だったか」も判定条件です。個数だけを変えても続行が自動的に決まるわけではなく、追加後の判定規則を新たに定義する必要があります。

期待する効果は、ハンド奪取がその手の捕獲・種まきの展開に直結することです。一方、一着手の長さ、連続捕獲の増加、循環、先後差への影響が案Aより大きい可能性があります。これらも未検証です。

「2回目の捕獲分を蒔き終えた直後に追加する」のか、「通常なら着手が止まる終点まで待って追加する」のかは未確定です。両者を同じ仕様として扱わず、試験前にどちらを採るか固定します。

## 試験前に確定する細則

1. 自分の追加用ハンドが0個の場合は不発とするか。相手の最後の1個保護と、一着手1回の制限を正式に固定するか。
2. 案Bの追加時点と、追加後の空穴判定・捕獲判定・連続種まき判定の順序。
3. 後列終点と、所有中NYUMBAの停止・使用選択への適用。NYUMBAへ追加した結果6個に達する場合の扱い。
4. 相手前列全空による即時終局では捕獲分を蒔かないため、終点が新たに生じない。両案で追加を省略するかなど、終局との優先順位を固定する。追加で終局を取り消さない。
5. 両者のハンドが空になる着手をNAMUAで最後まで処理し、その後共通MTAJIへ移る時点と、片側枯渇・パスの扱い。
6. 現行棋譜との識別、追加の時点・穴・両者の消費数を記録する方法。現行の確保分を含む途中局面を新案へ暗黙に変換しない。

## 検証候補と採用判断

- 遷移：総KETE保存、両者のハンド消費、最後の1個保護、一着手1回、空穴・後列・NYUMBA・即時終局・残数不足の境界。
- 進行：通常終局率、パス、NAMUAの長さ、総手数、一着手の捕獲・連続種まき回数、循環と安全上限による停止。
- 戦略と均衡：終点の補強が利益・不利益となる棋譜、先後交換による比較、方針を変えた対局、必要に応じた必勝ルート調査。
- 操作：追加2個の出所と投入先を理解できる表示、案Bで増える一着手の処理を追えること。
- AI：探索用遷移を各案に対応させて通常遷移と照合する。現行の凍結モデルの学習・評価・棋力実績を新規則へそのまま引き継がない。
