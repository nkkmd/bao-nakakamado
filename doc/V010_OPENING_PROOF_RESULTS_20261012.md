同じ開幕で3方針の結果が変わるのは10通り。例えば「6番・左→5番・右」は現行8,192同士では先攻4勝だが、同じ評価で探索量だけを32,768へ増やすと後攻4勝。逆に「6番・左→6番・右」は現行8,192同士で後攻4勝、32,768同士・可動性8,192同士では先攻4勝となった。初手だけでなく応手、その後の探索と評価の組み合わせが影響する。

「7番・左→5番・右」は3同方針とも先攻4勝だった。しかし後攻の応手を「5番・左」へ変えると現行8,192／32,768では後攻4勝となる。したがって初手7番・左を先攻必勝手として推薦しない。

「7番・右→7番・右」の可動性同士だけは先攻2勝・後攻2勝で、2seedの勝者が異なる。全セルが一つの勝者へ固定されたわけではない。全14開幕を合算した比率は自然な初期配置の先攻勝率として使わず、狭い信頼区間も算出しない。

## 2．自由な初期局面と担当交換

以下は初手・応手を強制しない参照28局。強制開幕392局と分ける。

| 先攻の方針 | 後攻の方針 | 4局の結果 |
|---|---|---|
| 現行8,192 | 現行8,192 | 後攻4勝 |
| 現行32,768 | 現行32,768 | 後攻4勝 |
| 可動性8,192 | 可動性8,192 | 後攻4勝 |
| 現行8,192 | 可動性8,192 | 先攻4勝 |
| 可動性8,192 | 現行8,192 | 後攻4勝 |
| 現行8,192 | 現行32,768 | 後攻4勝 |
| 現行32,768 | 現行8,192 | 先攻4勝 |

同方針3条件はいずれも後攻4勝だった。現行8,192／32,768は初手6番・右、後攻7番・右を選び、可動性同士は初手6番・左、後攻5番・右を選んだ。異なる開幕でも後攻勝ちになったという観測だが、各条件2seedの限られた固定AIの結果である。

担当交換では32,768ノードの現行方針が8,192ノードの現行方針に、先攻でも後攻でも4勝した。両割当の初手・応手は同じ「6番・右→7番・右」だった。これは開幕以降の探索量の差でも勝敗が変わる証拠であり、後攻という手番だけで結果を説明できない。

現行8,192も可動性8,192に両担当で4勝した。診断用可動性評価を強い評価器として選び直したり、今回の結果で重みを調整したりしていない。これらの担当交換を同方針同士の先後差に混ぜない。
