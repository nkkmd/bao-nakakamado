## 3案の定義

| 案 | 片側のハンドが先に0になった後 | 現在の扱い |
| --- | --- | --- |
| 現行パス | 空の側はパス。両ハンドが0になるまで相手が実質的に連続着手し、その後に両者がMTAJI。 | v0.4の基準。v0.5.1では全投入条件以外に適用 |
| 個別MTAJI | 空の側だけ次の自分の手番からMTAJIの合法手で着手。相手はハンドが残る間NAMUA。 | 検討候補・未実装 |
| 一穴全投入 | 空の側は現行どおりパス。相手は次のNAMUA着手で、穴と方向を一度選び、残りのハンドの全KETEをその一穴に置いてから通常の捕獲・連続種まきを処理。両者のハンドが0になればMTAJI。 | v0.5.1で試用・正式採用未決定 |

個別MTAJIの混合段階における合法手・終局境界はまだ最終仕様ではない。一穴全投入はv0.5.1の画面と棋譜へ試用実装した。運要素の検討は引き続き凍結する。

## 現在の試験が示したこと

[個別MTAJIの先後差試験](FIRST_PLAYER_BALANCE_20260929.md)は、現行パスとの同条件比較で次を観察した（各手選び1,000局、先攻はSOUTH）。「先に空の側の勝ち」の分母は、片側だけ先に0になった対局数。

| 手選び | 先に空の側の勝ち：現行 → 個別MTAJI | `no-move`：現行 → 個別MTAJI | 平均手数：現行 → 個別MTAJI | 先攻勝率：現行 → 個別MTAJI |
| --- | ---: | ---: | ---: | ---: |
| 無作為 | 70/739 → 203/739 | 30 → 120 | 41.7 → 48.7 | 47.9% → 49.4% |
| 簡易評価＋揺らぎ | 17/545 → 88/545 | 7 → 83 | 34.4 → 37.2 | 46.8% → 47.1% |
| 一手評価 | 23/584 → 90/584 | 28 → 218 | 35.2 → 38.2 | 45.1% → 44.6% |

個別MTAJIでは空ハンド側のパスがなくなり、先に空になった側の勝つ余地が増えた。一方、`no-move` の終局と平均手数が増えた。応手評価の300局では奪取が発動せず、両方式の違いを評価できなかった。

[一穴全投入の局面・先後差試験](FIXED_PIT_BULK_STUDY_20260930.md)は、**別のseedと手選びの進め方**で現行パスと比較した（各手選び1,000局）。

| 手選び | 先に空の側の勝ち：現行 → 一穴全投入 | `no-move`：現行 → 一穴全投入 | 平均手数：現行 → 一穴全投入 | 先攻勝率：現行 → 一穴全投入 |
| --- | ---: | ---: | ---: | ---: |
| 無作為 | 72/763 → 229/763 | 36 → 147 | 43.3 → 49.4 | 46.8% → 50.7% |
| 簡易評価＋揺らぎ | 24/535 → 108/535 | 13 → 71 | 35.4 → 37.0 | 50.6% → 51.0% |
| 一手評価 | 21/555 → 99/555 | 24 → 169 | 35.5 → 37.5 | 45.8% → 47.0% |

全投入案でも先に空になった側の勝つ余地が増え、`no-move` と平均手数も増えた。初期局面からの探索入り応手評価（各1,000局）では、全投入案の先攻勝率は52.2%と52.6%。到達可能なハンド枯渇局面2,400標本から応手評価で再開した試験では、全投入が全局面で発動し、空ハンド側の勝ちは現行の29局から346局へ、`no-move` は47局から582局へ変化した。後者は**ハンド枯渇後に条件を付けた比較**であり、ゲーム全体の先後勝率とは解釈しない。全投入で増えた `no-move` の大半は全投入の直後ではなく、その後のMTAJI中に起きた。

二案の表は、それぞれ**現行パスとの差**を読むためのもの。個別MTAJIと一穴全投入の数値を横に並べて優劣や先後差の大小を決めない。共通の局面・seed・手選びによる三者の直接比較は未実施である。いずれの簡易方針も人間や強いAIの最適な着手を表さず、先攻後攻の均衡を証明していない。

## 人間対局に進む時点の暫定順位

**採用候補としては、①個別MTAJI、②一穴全投入、③現行パス**とする。これは試験結果だけで確定した順位ではなく、空ハンド側に選択の機会があるかを重視した暫定判断である。

1. **個別MTAJI** — 空になった側が次の手番で盤上のKETEを使える。パスの連続を解消し、本人の選択で逆転を目指せる。一方、両者の段階が違う局面や `no-move` 敗北をプレイヤーが理解できるかは未確認。
2. **一穴全投入** — 両者の段階を共有したまま、相手に一度だけ大きな着手を与える。穴・方向の選択には意味があるが、空ハンド側はその間に応手できない。大量投入後の捕獲や、後続の `no-move` を予測・納得できるかは未確認。対局が短くなるという仮説も支持されなかった。
3. **現行パス** — 仕組みは単純で比較の基準になる。ただし先に空になった側の勝率が低く、手を選べない時間が続く。これを意図的な厳しい罰則として受け入れられるかは未確認。

個別MTAJIの混合段階が理解しにくい、または空ハンド側に事実上の有効手がない場面が多いなら、①と②の順位は再検討する。順位を確定する前に、三案を**同じハンド枯渇局面から**比較する試験も有用である。

## 人間による確認の順序と観察点

比較の構想では対局・局面再生を**現行パス → 個別MTAJI → 一穴全投入**の順に行う。v0.5.1では一穴全投入から人間の確認を始める。最初の案を基準にすると、後二案の変化を説明しやすい。先後を入れ替え、ハンドが自分の最後の投入で0になる局面と相手に最後の1個を奪われる局面、全投入が少数・多数の局面、捕獲・非捕獲、`no-move` 前後を含める。主観的な感想だけでなく、着手前の予測と実際の結果を記録する。

- ハンドが0になった人が、次に自分は何を選べるかを説明できるか。
- 個別MTAJIでは、両者が違う段階にいること、捕獲義務と合法手、負けの理由を理解できるか。
- 全投入では、何個をどの穴へ置き、捕獲・連続種まきがどう続いたかを追えるか。相手が応手できないことを公平と感じるか。
- `no-move` や連続パスの終局を、事前に予測できたか。避ける選択があったと納得できるか。
- 手数だけでなく、待ち時間、選択の意味、逆転の余地、もう一局遊びたいかを比較する。

現時点で人間同士の実測はなく、視認性・納得感・面白さの結論は出していない。試作 v0.5.1 では一穴全投入を試用中。個別MTAJIは未実装で、どちらも正式採用は未決定。
