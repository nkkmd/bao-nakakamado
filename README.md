# Bao Nakakamado

Bao la Kiswahili を出発点に設計・試作する新しいBaoです。

**現在は試作v0.6.1：各人1列8穴・端で折り返す種まき・初期ハンド12個を試用しています。NYAKUA（ニャクア）と一穴全投入を維持しています。最終的な公開版の仕様は未確定です。**

## 遊べる試作

[`prototype/`](prototype/) の中身を静的サイトとして配信すると遊べます。2人対戦と簡易コンピューター対戦に対応します。

- 後列をなくし、盤は両者合計2列16穴。初期盤上は各人10個、ハンド12個、KETEは合計44個です。
- 種まきは自分の8穴で折り返します。8番の次は7番、1番の次は2番。反転後の方向は同じ着手の連続種まきにも引き継ぎます。
- NAMUAの一着手で2回以上捕獲すると、相手のハンドが2個以上なら1個奪う[NYAKUA（ニャクア）](doc/TERMINOLOGY.md)が発動します。相手の最後の1個は奪えません。
- 相手のハンドが0なら、残り2個以上のハンドを合法な開始穴へ一度に全投入します。空になった側は両者のハンドが0になるまでパスし、その後共通でMTAJIへ移ります。

[現行ルールブック](doc/RULEBOOK.md)に全体の遊び方、[試作README](prototype/README.md)に起動・配信方法、[v0.6.1の最後の1個保護と進行確認](doc/NYAKUA_PROTECT_LAST_20261001.md)に変更点と確認範囲をまとめています。

## 検証と今後

旧v0.6.0での[折り返し方式の調査](doc/ONE_ROW_BOUNCE_STUDY_20261001.md)では、主試験6,000対局と追加2,300対局が通常終局し、前回の逆端へ循環する方式で見つかった無限循環の手も正常に停止しました。各人1列・ハンド12個の平均は着手方針により約12〜20手番でした。すべての局面の停止や先後均衡を証明した結果ではありません。

[初期ハンド12個・8個の比較](doc/HAND12_VS_HAND8_BALANCE_20261001.md)と[6個の追加試験](doc/HAND6_BALANCE_20261001.md)では、探索方針で先手への偏りが見られました。6個は変更前のv0.6.0の初期局面から、先手が13手番以内に勝ちを保証できる手順を全応手で検証しています。これらは最後の1個を奪える旧ルールの結果であり、v0.6.1へ必勝手順や勝率を引き継ぎません。現行試作のハンド12個は維持し、[再現用コードと結果](tools/hand-balance/README.md)を保存しています。

[最後の1個保護の進行確認](doc/NYAKUA_PROTECT_LAST_20261001.md)では、新旧各4,000対局が通常終局しました。一穴全投入とMTAJI移行は維持され、通常の初期局面からのパスは生じなくなります。[現行仕様の先後比較](doc/CURRENT_FIRST_PLAYER_BALANCE_20261001.md)では、主試験29,000局を実施しました。単純方針では先手勝率47.82〜53.68%ですが、4手探索60.8%、6手探索100%（1,000局）となり、探索方針では先手への偏りが残ります。先手必勝は未証明です。

[NYUMBA残数で2回目以降の捕獲数を制限する案](doc/NYUMBA_CAPTURE_CAP_STUDY_20261001.md)は、成立確認後、2026年10月1日に採用を見送りました。新案4,200局は通常終局しましたが、応手を見る方針では先手への偏りが増す結果で、先後均衡の改善は確認できませんでした。現行v0.6.1は毎回全捕獲する処理を維持し、[再現用コードと結果](tools/nyumba-capture-cap/README.md)を調査履歴として保存しています。

人間対局で、短さが十分か、端で反転する動きが分かりやすいか、NYAKUAと一穴全投入の選択が面白さにつながるかを確認します。片側だけ先にMTAJIへ入る案は実装していません。勝負宣言・抽選・追加手番は削除済みで、運要素の検討は凍結しています。

過去の4列盤での[先後比較](doc/FIRST_PLAYER_BALANCE_20260929.md)、[一穴全投入の調査](doc/FIXED_PIT_BULK_STUDY_20260930.md)、[ハンド枯渇3案の比較](doc/HAND_EXHAUSTION_OPTIONS_REVIEW_20260930.md)は履歴として残しています。旧盤の数値・評価を現行ルールへ引き継ぎません。

## 設計の方針

[元ゲーム](https://github.com/nkkmd/bao-la-kiswahili-game)と[採用ルール基準](https://github.com/nkkmd/bao-la-kiswahili-game/blob/main/doc/RULES_BASELINE.md)を出発点に、変更点を明記して試作し、分かりやすさ、選択の意味、長さ、先後の偏りを評価します。ルールを固定してから、新ルールに対応したAIと検証方法を検討します。

元ゲームの公開AIの強さ、研究上の厳密解・勝率は、新しいルールの結論として引き継ぎません。


同数ハンド・先後のハンド差・NYUMBA4個基準・配置分散を順に調べた[先後バランス改善候補の比較報告](doc/BALANCE_OPTIONS_STUDY_20261001.md)も保存しました。19条件と5条件の別seed確認で改善傾向はありましたが、方針を通じた均衡は確認できず、その調査の初期条件案は製品ルールへ採用していません。最後の1個保護は別途v0.6.1へ採用しました。
