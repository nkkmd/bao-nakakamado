# Bao Nakakamado

Bao Nakakamado は、Bao la Kiswahili を出発点として検討する新しい Bao の仮称です。このリポジトリに設計、試作、検証を記録します。

**現在の状態：遊べる試作 v0.4。KETE移動ルールの正式採用、公開版の仕様は未確定。**

## 遊べる試作

[`prototype/`](prototype/) に、Bao la Kiswahili のルールエンジンと画面デザインを土台にした試作を置く。NAMUA中の一手で2回以上捕獲すると、相手のハンドからKETEを1個自分のハンドへ移す。着手中のKETEの移動は盤面と状態表示で自動再生し、終わると次の手番へ進む。2人対戦と簡易コンピューター対戦に対応する。詳しい条件、検証範囲、ローカル起動方法、Cloudflare Pages の設定は [試作のREADME](prototype/README.md) を参照。

v0.1の勝負宣言、抽選、追加手番は試作から削除した。運・確率・期待値を使う仕組みの検討は一旦凍結する。

## 目指す方向

- Bao la Kiswahili の戦略性を残しながら、初めて遊ぶ人にも状況と選択肢を理解しやすくする。
- 捕獲やハンドなど既存の資源に結び付いた新しい戦略を、一つずつ試作して評価する。
- 元のゲームの合法手と終局判定を出発点とし、石を蒔く、連続種まき、捕獲、前後列を使う判断を活かす。

「遊びやすさ」が説明・表示の改善で得られる部分と、ルール変更が必要な部分も分けて評価する。現在のKETE移動ルールは試作段階であり、先攻・後攻差、NAMUAの長さ、連続捕獲の頻度、対局時間を確かめてから採用を判断する。

## 次の検討項目

[ハンド枯渇時の3案の暫定評価](doc/HAND_EXHAUSTION_OPTIONS_REVIEW_20260930.md)に、現状の試験結果、採用候補の暫定順位、人間対局で確認する点をまとめた。現在の試作は現行パス方式であり、採用案は未決定である。

ハンドが先に空になった側をパスさせる現行方式と、その側だけ先にMTAJIへ入る案を比較する。後者はハンド枯渇後も着手でき、探索的な試験では逆転の余地が増えた一方、合法手なしの終局も増えた。[検討記録と比較条件](doc/HAND_EXHAUSTION_PHASE_CANDIDATE.md)に、未決定の境界条件と次の検証手順を記した。先行MTAJIはまだ採用しておらず、現在の試作はパス方式で動く。先攻・後攻差と両方式の追加比較は[探索的試験記録](doc/FIRST_PLAYER_BALANCE_20260929.md)を参照。着手方針によって先攻勝率の方向が変わり、均衡は未確認である。

もう一つの候補として、相手のハンドが0になった後、次のNAMUA着手で自分のハンドの全KETEを選んだ一穴に置く案を[局面・先後差の探索的調査](doc/FIXED_PIT_BULK_STUDY_20260930.md)で検証した。合法手なしの増加と手数の延長を確認したため、採用は未決定である。試作 v0.4 には適用していない。

## 検討の順序

1. [現行ゲーム](https://github.com/nkkmd/bao-la-kiswahili-game)と[採用ルール基準](https://github.com/nkkmd/bao-la-kiswahili-game/blob/main/doc/RULES_BASELINE.md)を参照し、変更点を明記する。
2. 最小の試作で人間同士の対局を確認し、ルールの分かりやすさ、選択の意味、対局の長さ、先後の偏りを評価する。
3. ルールを固定してから、新ルールに対応するAIと検証方法を検討する。

元リポジトリのエンジン、UI、テスト、研究上の測定・検証方法は参照可能な出発点である。ただし、元ルールでの勝率、厳密解、AIの強さ、研究結果を新ルールでの結論として引き継がない。研究上の問いとゲーム・AIの採用判断も区別して記録する。
