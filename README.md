# Bao Nakakamado

Bao la Kiswahili の実装を出発点に、NYAKUA（ニャクア、ハンド奪取）を追加したBaoです。

**Bao Nakakamado・NYAKUAの考案者：nkkmd／初公開日：2026年9月30日。** [考案・公開・変更履歴](doc/ORIGIN_AND_HISTORY.md)に、考案・名称採用・各版の変更と根拠を記録しています。

**現行は試作v0.8.0：各人の前列・後列16穴、循環種まき、ハンド22個。NYAKUAの最後の1個保護と、別確保した奪取分を次の自分の手番で使う3個投入を採用しています。**

## 遊べる試作

[`prototype/`](prototype/) を静的サイトとして配信すると遊べます。2人対戦と簡易コンピューター対戦に対応します。

- 前列・後列を使う4列32穴へ戻しました。前列6・2・2、後列は空、ハンド22個ずつ、総KETE64個。
- 自分の前後列16穴を循環して蒔きます。捕獲するのは相手の前列です。
- NAMUAの一着手で捕獲2回以上、相手ハンド2個以上ならNYAKUAで1個奪います。**最後の1個は奪いません。**
- 奪取分1個を別に確保し、次の自分の手番で通常ハンド2個と合わせて**同じ合法な開始穴へ3個投入**。通常ハンドが1個なら計2個、0個なら確保分1個です。確保分は奪われません。
- 両者の通常ハンドと確保分がすべて0で共通MTAJIへ移行。相手前列全空または相手の合法手なしで勝ちです。

[ルールブック](doc/RULEBOOK.md)、[用語・仕様履歴](doc/TERMINOLOGY.md)、[起動・棋譜・テスト](prototype/README.md)、[今回の実装と検証](doc/NYAKUA_THREE_ADOPTION_20261002.md)を参照してください。

## 設計・実装の基準

[コンピューター導入計画](doc/AI_INTEGRATION_PLAN_20261004.md)に、AI-GEN4の探索機構と論理ゲート型評価器を本ゲームへ適応する手順を記録しています。[ニャクア込みの探索用遷移の検証](doc/AI_SEARCH_TRANSITION_VERIFICATION_20261004.md)では、128局・24,887候補遷移の一致を確認しました。[探索機構と手作り評価関数の実装](doc/AI_SEARCH_IMPLEMENTATION_20261004.md)では、107局面・1,926構成が全探索と一致しました。その探索実装の時点では学習・棋力比較は後続工程でした。画面のコンピューターは簡易方式のままです。

[元ゲーム](https://github.com/nkkmd/bao-la-kiswahili-game)と[採用ルール基準](https://github.com/nkkmd/bao-la-kiswahili-game/blob/main/doc/RULES_BASELINE.md)を出発点に、変更点を明記します。takasia未実装、連続種まきの安全上限など、保存済みエンジンの実装範囲を引き継ぎます。

[教師データ・モデル入力・学習の設計](doc/AI_LEARNING_DESIGN_20261004.md)では、368bitの専用入力と、データ分割・除外・再開のパイロット96単位を整備しました。このパイロットでは本学習・独立の最終評価を行っていません。

[実時計の教師試走](doc/AI_TEACHER_FEASIBILITY_20261004.md)では、通常ハンド0・確保分1の到達棋譜4件を含む64局面すべてが深度4で完了しました。教師の条件と正式収集の最低件数を固定しました。[正式収集基盤の実装・候補監査](doc/AI_FORMAL_COLLECTION_INFRASTRUCTURE_20261004.md)では、除外一覧・生成・監査・暗号化保存・artifact復元・封印を整備しました。81テストと全7 CIジョブが成功し、開発用96件の復元は新規計測0件で通過しました。v1の正式候補は必要層不足で保留しました。続く[選択計画v2](doc/AI_FORMAL_SELECTION_V2_20261005.md)では、同じseed範囲・候補・split割当・8192要求上限・最低件数で必要層を先に確保し、すべての候補条件を通過し、89テストと全8 CIジョブも成功しました。正式収集v2の8192件を完了し、採用後の再監査・封印も通過しました。

PR #17をmainへ統合し、正式収集workflowを登録しました。修正後のCIは89テスト・全8ジョブ成功。収集鍵を新規設定し、正式収集v2のrun 37245789837は全18ジョブ成功しました。8192件を受理し、train 5019行・validation 1517行の全条件を通過。最終検証データを暗号化したまま封印し、学習準備へ進みました。[正式収集の実行記録](doc/AI_FORMAL_COLLECTION_RUN_V2_20261005.md)を参照してください。

[正式学習の仕様・実装検証](doc/AI_FORMAL_LEARNING_DESIGN_20261005.md)で、線形・MLP・論理ゲートの学習器、固定validation基準、整数推論、checkpoint再開、手動workflowを整備しました。この仕様・実装検証の時点では、正式の本学習・最終開封・公開AIへの採用は行っていません。

[正式学習の実行記録](doc/AI_FORMAL_LEARNING_RUN_20261005.md)で、初回のゼロ符号検証の停止・修正と、修正後の全11ジョブ成功を保存しました。全9候補が固定validation基準を通過し、事前の中央値順位で線形seed 2026100401を凍結しました。学習完了時点の最終評価は未開封でした。後続の正式最終評価は以下の実行記録を参照し、棋力・実機試験と公開AIへの採用は別工程です。

[最終評価の準備](doc/AI_FORMAL_FINAL_PREPARATION_20261005.md)で、凍結した線形候補だけの合否条件と、GitHubに残る受付記録による重複防止を整備しました。開発用テスト・推論照合を行う読取り専用CIを追加しています。準備時点の正式finalは未開封でした。後続の[手動workerと結果保存](doc/AI_FORMAL_FINAL_WORKER_20261005.md)をPR #21でmainへ統合し、具体的な明示承認後に一度だけ[正式最終評価](doc/AI_FORMAL_FINAL_RUN_20261005.md)を実行しました。1,656局面・782開幕グループで固定18条件をすべて通過し、整数推論の不一致0件・反対称性も全件通過。公開AIへの採用前に、探索接続・同時間対局・実機検証を行います。

元ゲームの公開AIの強さや研究結果を、今回の試作へそのまま適用しません。片側だけ先にMTAJIへ入る案は採用していません。勝負宣言・抽選・追加手番は削除済みで、運要素の検討は凍結しています。

[v0.8.0のファイル整合監査](doc/V080_CONSISTENCY_AUDIT_20261002.md)に、文書・試験案内・CIの更新内容と検証結果を記録しています。

[凍結線形モデルの探索接続](doc/AI_MODEL_SEARCH_CONNECTION_20261005.md)では、元の教師探索と凍結条件を維持した別入口を追加しました。除外済み89局面・1,602構成が通常遷移による全探索と一致し、Python／JavaScriptの整数評価178件も不一致0。PR #22は新規CI・旧準備CI・既存全8ジョブ成功後にmainへ統合しました。次は同時間対局の試走と正式比較条件の固定です。棋力・実機・公開AIの採用は別工程です。
