# Bao Nakakamado

Bao Nakakamado は、Bao la Kiswahili を出発点として検討する新しい Bao の仮称です。このリポジトリに設計、試作、検証を記録します。

**現在の状態：構想段階。新ルール、実装、公開・採用判断は未確定。**

## 目指す方向

- Bao la Kiswahili の戦略性を残しながら、初めて遊ぶ人にも状況と選択肢を理解しやすくする。
- 新しい戦略を生む余地を検討する。
- 運要素は単なる偶然の勝敗ではなく、ポーカーや麻雀のように確率・期待値を読み、局面に応じてリスクを取るか避けるかを選ぶ要素として検討する。

まずは Bao la Kiswahili の通常の着手と勝敗判定を出発点とし、期待値をコントロールできる仕組みを**一つずつ**加える方向を優先する。石を蒔く、連続種まき、捕獲、前後列を使う判断など、元のゲームの核をどこまで維持するかは、具体的なルール案と試作で確認する。「遊びやすさ」が説明・表示の改善で得られる部分と、ルール変更が必要な部分も分けて評価する。

## 確率要素の設計条件

現時点では、次を満たす仕組みを候補とする。具体的な抽選方法、効果、頻度、利用条件はまだ決定していない。

1. プレイヤーが局面を見て、リスクを取るか温存するかを選べる。
2. 確率を理解でき、過去の結果を踏まえて判断を更新できる。公開された有限の共通抽選要素と残数表示は候補の一つ。
3. 同じ確率でも盤面によって選択の価値が変わり、判断が戦略に結び付く。
4. 効果の大きさと利用機会を制限し、偶然の一回だけで決着しにくくする。
5. 石の総数、合法手、捕獲、局面の再現、終局条件との整合を確認する。

ランダムな初期配置は今回の「期待値コントロール」の中心案とはしない。具体的な成功・失敗の効果は、元のルールとの整合と、実際に選択を迷う価値があるかを比較してから決める。

## 検討の順序

1. [現行ゲーム](https://github.com/nkkmd/bao-la-kiswahili-game)と[採用ルール基準](https://github.com/nkkmd/bao-la-kiswahili-game/blob/main/doc/RULES_BASELINE.md)を参照し、維持する規則と変更候補を明記する。
2. 一つの確率要素について複数の小さな案を作り、情報の公開範囲、意思決定の時点、成功・失敗の効果、回数制限を比較する。
3. 最小の試作で人間同士の対局を確認し、理解しやすさ、選択の意味、対局の長さ、先後の偏りや勝敗への影響を評価する。
4. ルールを固定してから、新ルールに対応するAIと検証方法を検討する。

元リポジトリのエンジン、UI、テスト、研究上の測定・検証方法は参照可能な出発点である。ただし、元ルールでの勝率、厳密解、AIの強さ、研究結果を新ルールでの結論として引き継がない。研究上の問いとゲーム・AIの採用判断も区別して記録する。

この文書は構想の記録であり、具体的なゲームルールや実装仕様を確定するものではない。
