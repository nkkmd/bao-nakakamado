# Bao Nakakamado

Bao la Kiswahiliをベースに、独自ルール **NYAKUA（ニャクア）** を採用したオリジナルのBaoです。盤・種まき・捕獲の仕組みを受け継ぎ、ハンドのKETEを使った駆け引きを加えています。

**Bao Nakakamado・NYAKUAの考案者：nkkmd／初公開日：2026年9月30日。** [考案・公開・変更履歴](doc/ORIGIN_AND_HISTORY.md)に名称・版・採用の根拠を記録しています。

**現行ルール：v0.10.0。** v0.9.0のNYAKUA案A「着手終了後の終点2個追加」を維持し、2026年10月9日に原型Bao la Kiswahiliで正式採用された **takasia** を基礎規則として追加しました。旧v0.8.0・v0.9.0の記録は保存しています。

## 遊べる試作

[`prototype/`](prototype/)を静的サイトとして配信すると遊べます。**2人対戦・簡易コンピューター・探索コンピューター（試験）**に対応します。[現行探索の実装・検証](doc/AI_V010_SEARCH_IMPLEMENTATION_20261009.md)では、ブラウザー検証と独立した512局比較を完了し、現行簡易AIに対して487勝・25敗で固定基準を通過しました。実機確認・公開採用は後続工程です。画面の版表示は「試作 v0.10.0」です。

- 両者4列32穴、各人の前列6・2・2、後列は空。ハンド22個ずつ、合計64個。
- 自分の前列と後列を循環して蒔き、相手の前列を捕獲します。
- NAMUAで一手に2回以上捕獲し、通常処理完了時に自分のハンド1個以上・相手2個以上があれば、双方から1個ずつ終点へ計2個追加します。相手の最後の1個は保護します。
- 一手につき一度で、追加後の再判定・捕獲・種まきはありません。後列やNYUMBA停止穴も対象。即時終局・安全停止では追加しません。
- 各手の開始時の投入は通常1個。別確保・次手3個投入は廃止しました。
- 両ハンド0で共通MTAJIへ移行。MTAJIのtakata後に条件を満たすとtakasiaが成立し、相手の次の1手だけ対象穴からのtakata開始を禁止し、最後のKETEが対象穴へ入ればそこでrelay sowingを停止します。
- 前列全空または合法手なしで敗北です。既知の循環では512回の安全上限で停止し、通常勝敗と区別します。

[ルールブック](doc/RULEBOOK.md)、[用語・棋譜](doc/TERMINOLOGY.md)、[起動・配布・検証](prototype/README.md)、[v0.10.0 takasia実装記録](doc/TAKASIA_V010_IMPLEMENTATION_20261009.md)、[v0.9.0のNYAKUA採用記録](doc/NYAKUA_V090_ADOPTION_20261007.md)を参照してください。先後均衡・初期局面の必勝・全局面の停止は未確定です。
