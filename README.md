# Bao Nakakamado

Bao Nakakamado は、Bao la Kiswahili を出発点として検討する新しい Bao の仮称です。このリポジトリに設計、試作、検証を記録します。

**現在の状態：遊べる試作 v0.5.1 で一穴全投入を試用中。ハンド奪取の名称はNYAKUA（ニャクア）に決定。NYAKUAのルールと一穴全投入の正式採用、公開版の仕様は未確定。**

## 遊べる試作

初期配置から捕獲、NYAKUA、一穴全投入、MTAJIまでの全体の遊び方は、[現行試作のルールブック](doc/RULEBOOK.md)を参照。

[`prototype/`](prototype/) に、Bao la Kiswahili のエンジンと盤面デザインを土台にした試作を置く。NAMUA中の一着手で2回以上捕獲すると、相手のハンドからKETEを1個自分へ移す。この動作を[NYAKUA（ニャクア、ハンド奪取）](doc/TERMINOLOGY.md)と呼ぶ。相手のハンドが0なら、残り2個以上のハンドのKETEを一度選んだ穴へ**一度に**全投入し、通常の捕獲・連続種まきを続ける。投入を一画面で示し、その後の着手を盤面と状態で自動再生する。2人対戦と簡易コンピューター対戦に対応。条件、検証、起動方法は[試作のREADME](prototype/README.md)を参照。

v0.1の勝負宣言、抽選、追加手番は削除した。運・確率・期待値を使う仕組みの検討は一旦凍結する。

## 目指す方向

- Bao la Kiswahili の戦略性を残しながら、初めて遊ぶ人にも状況と選択肢を理解しやすくする。
- 捕獲やハンドなど既存の資源に結び付いた新しい戦略を、一つずつ試作して評価する。
- 元のゲームの合法手と終局判定を出発点とし、石を蒔く、連続種まき、捕獲、前後列を使う判断を活かす。

## 次の検討項目

[現行パス、個別MTAJI、一穴全投入の暫定評価](doc/HAND_EXHAUSTION_OPTIONS_REVIEW_20260930.md)には、試験結果、試用前の暫定順位と人間対局での観察点を記録した。v0.5.1は**パスと共通段階移行を維持したうえで一穴全投入を試す版**である。片側だけ先にMTAJIへ入る案は[仕様候補](doc/HAND_EXHAUSTION_PHASE_CANDIDATE.md)に記録し、まだ実装していない。

一穴全投入の[探索的調査](doc/FIXED_PIT_BULK_STUDY_20260930.md)では、先に空になった側の勝つ余地と `no-move` 終局、平均手数が増えた。先後均衡の証明や採用判断にはならない。[試用版の仕様と確認点](doc/FIXED_PIT_BULK_TRIAL_20260930.md)に実装・検証範囲をまとめた。個別MTAJIとの共通条件での直接比較、人間の納得感の確認を続ける。

## 検討の順序

1. [現行ゲーム](https://github.com/nkkmd/bao-la-kiswahili-game)と[採用ルール基準](https://github.com/nkkmd/bao-la-kiswahili-game/blob/main/doc/RULES_BASELINE.md)を参照し、変更点を明記する。
2. 試作で人間同士の対局を確認し、分かりやすさ、選択の意味、対局の長さ、先後の偏りを評価する。
3. ルールを固定してから、新ルールに対応するAIと検証方法を検討する。

元リポジトリのエンジン、UI、テスト、研究上の測定・検証方法は出発点である。元ルールでの勝率、厳密解、AIの強さ、研究結果を新ルールでの結論として引き継がない。
